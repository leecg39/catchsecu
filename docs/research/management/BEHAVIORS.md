# 관리 화면 동작 조사

38개 경로 방문. 경로별 DOM/computed CSS/스크린샷 수집. 10개 대표 화면 768/390 캡처.

- 회사정보 수정은 편집 경로 이동. 원본 저장은 실행하지 않음.
- 보안정책 5개 탭 클릭으로 화면 변경; 각 탭 원문과 스타일/스크린샷 확보. 라디오 저장 실행 안함.
- 접근제한은 정적 메시지. 유료 소개에는 라이선스 알아보기.
- 로그 기본조회/특정 시간 조회는 탭. 특정 시간 조회 후 다른 관리 페이지가 캡처되는 Ego 동시조작 혼선으로 해당 상태는 미검증. log-service-specific.json은 근거로 사용하지 않음.
- 프로필 SSO 해제 및 인증 설정은 실행 안함. 클론은 데모 알림 제공.
- 서비스/메일/동의서 입력 및 발송 저장 실행 안함. 클론만 로컬 상태로 구현.
- 목록 데이터의 개인 이메일/담당자/IP는 구현에서 demo@example.com, 데모담당자, 127.0.0.1로 치환.
- 768/390에서 사이드바 숨김; 정보 두 열 유지. 테이블은 가로 스크롤.
- 최초 연속 탐색 중 잘못된 접근입니다 toast가 후속 페이지에 남아 일부 screenshot에 포함됨. 본문 사양에서 제외.
