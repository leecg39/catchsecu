# Workflow 데모 명세

- 대상: src/components/forms/Workflow.tsx
- 적용: 직접 접근에 서버 상태가 필요한 6경로 및 실제 ID가 없는 응답 3경로.
- 원본 정상 화면 미확인. 원본 충실도 달성을 주장하지 않는 로컬 워크플로.
- FormsEditor 임시저장 데이터만 localStorage에서 사용.
- 동의 설정 → 폼 설정 → 공유 → 목록의 로컬 연결.
- 실제 원본 저장, 발송, 공개, 동의 변경 없음.
- 제목/버튼은 추출 공통 CSS: heading24/700/33.6px; button40px radius4px #6558ff.
- 응답 데이터는 빈 표. ID 미확보 시 실제 응답 내용을 만들어내지 않음.

## 리뷰 수정 검증
- 개인정보 동의 목적/기간, 최대 응답 수, 제출 후 안내 여부를 DemoForm에 영속.
- 다음으로 이동할 때도 저장하고 설정 단계에서 공개 상태를 갱신.
- 응답은 catchsecu-responses-{formId}의 [{id,values}]를 읽고 질문 ID별 표 렌더링.
- 저장 모듈 복원/설정 영속/중복 방지/응답 연결 단위 검증 4건 통과.
- 공유 화면에서 /projects/{form.id} 로컬 응답폼 열기 및 절대 URL 복사 제공.
- 클립보드 권한 실패 시 읽기전용 URL 입력을 선택해 수동 복사 가능.
