# 서비스 화면 구현 상태

## 범위

문자, 이메일, 카카오 알림톡, 알림 연동, 라이선스 및 결제의 39개 경로를 처리합니다.

- 정적 경로 28개: 로그인한 원본에서 조회한 화면 또는 리다이렉트를 구현했습니다.
- 동적 경로 10개: 유효한 템플릿·거래 ID가 없어 원본을 확인하지 못했습니다. 확인 불가 안내를 표시하며 완료로 분류하지 않았습니다.
- `/pay/cancel`: 실제 구독 취소에 영향을 줄 가능성을 피하기 위해 원본을 열지 않았습니다. 확인 불가 상태입니다.

## 구현

`src/components/services/index.tsx`의 `ServicesPages`, `matchServices`를 사용합니다. 화면은 게이트 안내, 목록과 필터, 결제와 상품 카드, 카카오 메시지 미리보기로 분리했습니다.

탭·검색·페이지 크기·데모 등록·알림 추가·선택 삭제·결제 모달은 로컬에서 동작합니다. 실제 발송이나 결제 API를 호출하지 않습니다. 원본 확인 없이 만든 작업 모달은 데모임을 표시합니다.

## 근거 및 검증

- 원본 스크린샷 49개, 유형 및 컴포넌트 사양 19개, 추출 SVG 41개
- 실제 원본 텍스트, DOM 좌표, computed CSS, 이미지 주소, SVG 원문은 경로별 JSON에 저장
- 대표 화면 1440·768·390px 자료 저장
- `npx tsc --noEmit`: 통과
- 브라우저 시각 비교: 메인 작업자의 직렬 검증 대기

## 남은 한계

연 구독의 가격 변화와 모든 호버 상태는 확인하지 못했습니다. 원본 입력을 여러 탭에서 동시에 실행할 때 포커스 충돌 가능성이 발견되어 후속 브라우저 작업은 중단했습니다. 각 캡처의 URL과 본문을 대조하여 적용했으며, 미확인 경로와 최종 시각 검증 상태는 `services-coverage.json`에 구분했습니다.
