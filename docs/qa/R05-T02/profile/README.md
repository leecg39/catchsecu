# R05 서버 통합 검증

분리된 PostgreSQL 테스트 DB에서 관련 7개 파일의 225개 테스트가 통과했다.

- [기본 104건](baseline.json): 프로필·본인 활동·세션, 계정 폐쇄, 현재 권한 재확인, 활동 검토 요청·답변·처리·취소·알림·보유/파기, SSO 실패 복구.
- [SSO 121건](sso-integration.json): 연결 계정의 본인/회사 격리, 마지막 로그인 수단 해제 거부, 최근 인증, 연결 해제와 세션/대기 인증 폐기, 동시 처리와 감사 실패 롤백을 포함한 제공자/인증 흐름 회귀검사.

이 실행에서는 백엔드 동작을 변경하지 않았다. 실제 앱 프로세스에 대한 독립 HTTP 경계 검사는 [13건 결과](../../R05-T04/profile-flow/boundaries.json)에 별도로 기록했다. 외부 IdP 인증 및 실제 SMTP 수신 시험과는 구분한다.
