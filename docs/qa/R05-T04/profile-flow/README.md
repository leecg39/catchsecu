# R05 프로필·검토·탈퇴 로컬 수용 기록

새 합성 회사 A/B와 사용자 3명으로 구현을 확인했다. 전체 프로젝트 완료나 원본 내부 구현의 동일성을 뜻하지 않는다.

- [모델 대조](../../R05-T01/model-audit/README.md): 개발/테스트 DB의 6개 모델·70컬럼·28제약·22인덱스·10트리거 일치.
- [서버 테스트](../../R05-T02/profile/README.md): 관련 7개 파일, 225개 통과. 이번 범위에서는 서버 계약/스키마를 변경하지 않았다.
- [브라우저](../../R05-T03/profile-flow/README.md): 프로필·활동·세션·SSO 해제·검토·탈퇴 흐름, 네트워크 실패와 409 복구, 6경로/18폭 관측.
- [독립 HTTP 경계 13건](boundaries.json): 본인 범위, 다른 사용자/회사 거부, 역할/버전/중복/소유자 탈퇴 차단. 거부 요청 전후 DB 변경 없음.
- [로컬 알림 1건](review-mail.json): 해당 job만 실행, done/시도1/전달기록1, 메일 파일 해시 확인. 제목/본문은 메일에 포함하지 않음.
- [최종 8개 HTTP 및 DB](verified.json), [새 서버 프로세스 재검증](verified-after-restart.json): 상태 해시가 동일하다.

최종 상태는 회원 계정 `closed` v6, 세션/로그인 계정/인증 요소/비밀번호 이력/유예/사용자 인증 증명/서비스 권한 각 0건이다. 회사와 서비스는 운영 중이며, 회원 소속은 revoked v2다. 폐쇄 사유는 암호화돼 별도 기록에 남는다. 검토 3건은 각각 처리 완료·원문 파기(v5, 메시지0), 처리 완료·보존(v5, 메시지3), 요청 취소(v2, 메시지2)다. 감사 75건과 기존 원본 이벤트를 유지한다.

최종 상태 해시: `447616fcf1df22f82192de883b57c40639235614687ca5847b651c670fd98764`.

[초기 준비](prepared.json), [첫 검토 파기 준비](destruction-setup.json), [두 번째 검토 보유 상태 준비](second-retention-setup.json), [SSO 연결 준비](sso-setup.json)는 시험용 직접 입력을 명시한다. 최초 이메일 확인, 소속/권한, 합성 처리 이벤트, 보유 시계와 SSO 연결은 fixture 설정이며 실제 공급사 처리나 원본 데이터 수집으로 집계하지 않는다. 재시작 검증은 앱 서버에 대한 것이며 전역 worker 재시작은 수행하지 않았다.

실제 외부 SMTP/IdP와 원본 전체 상태·모든 권한/라이선스 조합은 미완료다. `partial_verified`와 `external_pending`을 유지한다.
