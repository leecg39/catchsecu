# R05-T04 내부 수용 완료·외부 대기

2026-10-11 현재 production 서버와 PostgreSQL에서 프로필·검토·탈퇴 최종 상태를 재검증했다. 전체 Task는 실제 외부 공급사 증거가 없어 `in_progress / external_pending`을 유지한다. 승인된 수용 조건에 따라 후속 내부 구현은 진행한다.

- 독립 HTTP 11건을 서버 재시작 전후 각각 통과했다. 두 활성 사용자는 새로 로그인해 본인 프로필만 읽으며, 탈퇴 사용자의 이전 세션과 새 로그인은 모두 401이다. 다른 회사의 검토 조회는 404다.
- 탈퇴 프로필 v6·소속 revoked v2, 세션/계정/인증요소/비밀번호이력/유예/proof/서비스권한 각 0건, 회사·서비스 active를 독립 DB 조회로 확인했다. 폐쇄 사유 암호문도 복호화 값과 대조했다.
- 검토 3건은 처리 완료/원문 파기 v5(메시지0), 처리 완료/보존 v5(메시지3), 취소 v2(메시지2)다. 도메인 감사21건과 로컬 메일 job done/시도1/영수증1/파일 해시를 보존한다.
- 로그인과 화면 조회의 session/analytics 감사를 제외한 업무 상태 지문 `20b65525c43be44981176bc7e2d70077c286cd0accc2408902e8fc1e132edcb6`가 서버 재시작 전후 동일했다. 과거 전체 감사75건을 포함한 지문과 범위가 다르다.
- Ego Lite의 재로그인 세션은 재시작 후 같은 3개 검토와 20행 설정을 표시했다. 별도 Codex 인앱 브라우저는 로그인으로 전환되어 세션 격리를 확인했고 임시 탭을 닫았다.
- 격리된 test DB에서 main worker를 별도 프로세스로 두 번 기동·정상 종료했다. 공유 dev DB의 보유기간 작업은 실행하지 않았다. 검토 메일 실패/재시도와 파기 상태 전이는 [R05-T02](../../R05-T02/current/README.md)의 PostgreSQL 회귀로 검증돼 있다.
- R05-T02의 서버264시험 이후 서버 소스 변경은 없었다. 이번 UI·감사·현재 권한·브라우저 뒤로 가기 회귀36개, 타입 검사, 전체 린트0오류/기존29경고, production82페이지와 새 검증 스크립트 린트를 통과했다. 두 시험 수는 중복을 포함하므로 합산하지 않는다.
