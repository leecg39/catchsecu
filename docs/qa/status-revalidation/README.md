## 재검토 이력과 다른 Task의 남은 결손

1. MFA 현황/설정 경로가 CloneApp의 대시보드 분기에 가려지는 것을 실제 Ego에서 재현했다. 수정 후 별도 화면 증거를 기록한다.
2. 월마감 조회/CSV와 기존 마감 반환은 tenantId만 제한하고 현재 서비스 범위를 재검사하지 않는다. 생성과 감사 저장도 다른 transaction이다. 다음 구현 우선순위다.
3. SSO/기관 인증, 알림톡 실발송/대체발송은 미연결 상태다. 일반 인증이나 503 거부 시험을 성공 연동으로 계산하지 않는다.
