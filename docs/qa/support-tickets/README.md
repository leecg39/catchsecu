# 문의·서비스 개선 제안 구현 기록

## 구현 범위

- migration 46 `SupportTicket`: 회사, 선택한 서비스, 작성자, 답변 담당자, 상태, 버전과 생성/수정 시각을 저장한다. 서비스는 `(tenantId, serviceId)` 복합 외래 키로 다른 회사와 연결되지 않는다.
- 제목·본문·답변은 AES-256-GCM으로 암호화한다. 삭제하면 암호문과 답변 정보를 지우고, 재시도 응답도 무효화한다. 감사 기록에는 필드명과 작업만 남긴다.
- `/api/v1/support-tickets`: 작성자 본인의 생성/목록/상세/접수 중 수정/답변 후 종료/삭제. 시스템 운영자는 전체 회사 목록/상세/답변/종료/재개/삭제.
- 대시보드 상단의 `문의`, `서비스 개선 제안` 버튼을 접수 폼에 연결했다. 작성자 목록·상세·작성 화면과 운영자 목록·상세·답변 화면을 추가했다.
- 생성 요청은 Idempotency-Key, 변경 요청은 버전을 요구한다. 서버에서 출처, 세션, 회사 범위, 운영자 권한과 속도 제한을 검사한다.
- 2026-10-03 추가: 작성자 목록과 상세, 운영자 목록과 상세의 복호화된 내용 열람을 감사 원장에 기록한다. 운영자 목록은 반환한 문의마다 해당 회사 ID로 기록한다. 권한 거부 요청은 열람 이벤트를 남기지 않는다.
