# P10-T05 결제 화면 — 무료 체험 이력 부분 검증

2026-10-03. `/pay/history`의 첫 탭을 실제 회사 구독 자료에 연결했다. P10-T02~T04의 외부 PG·원장·환불·월마감과 17개 경로 전체 수용 조건은 아직 충족하지 않아 P10-T05를 완료로 표시하지 않는다.

## 구현 범위

- `GET /api/v1/billing-history`: 현재 회사의 `trialing`·`expired` 무료 체험 구독만 읽는다. `billing.read`가 필요하고 회사별 범위를 적용한다. 미승인 `pending` 구매 요청은 결제·환불 이력에 포함하지 않는다.
- 한국 시간 달력 월을 기준으로 `fromMonth` 이상·`toMonth` 다음 달 미만을 필터링한다. 잘못된 기간과 페이지 크기는 거부한다. `REPEATABLE READ` 스냅샷에서 총건수와 페이지를 함께 조회한다.
- 화면은 기간 검색·초기화·페이지 이동과 실제 체험 시작/상태/0원/이용 기간을 표시한다. 문자 결제·본인인증 탭은 외부 원천이 없으므로 확정 기록 없음과 연동 상태를 설명한다.
- OpenAPI에 이 조회 경로와 월·페이지 매개변수를 기록했다.

## 검증

- `tests/server/subscriptions.test.ts`: 분리된 PostgreSQL에서 무료 체험과 실제 회사 ID 대조, 타 회사 분리, 미로그인 401·권한 없는 역할 403, 지난달 필터 0건, 역전 기간·범위 밖 연도·큰 페이지 거부, `pending` 구매 요청 제외를 확인했다. 관련 9건 통과.
- 허용 Node 24.19.0에서 TypeScript·변경 파일 ESLint 오류 0·production build를 통과했다.
- 전체 PostgreSQL 회귀는 25개 파일·408건 통과했다. 이후 화면 날짜 표시의 한국 시간대와 월 입력 연도 범위를 보정했고, 영향 범위 시험 9건·production build·ESLint·브라우저 QA를 다시 통과했다.
- [브라우저 실행 기록](browser.txt), [390px 화면](billing-history-mobile.png): production 서버에서 API 결과를 독립 DB 건수와 대조하고, 실제 체험 행 렌더링·미래 월 검색 결과 0건·초기화·가로 넘침 없음을 확인했다. 별도 headless Chromium을 사용했다.

## 남은 조건

- 원본 전체 결제 화면의 필터·상세·사용량·크레딧 및 17개 경로의 화면·권한 상태를 검증해야 한다.
- PG sandbox 승인·결제수단·환불/대사, 잔액 원장과 문자·본인인증 공급자 이력이 없으므로 유료 결제/환불/사용 기록은 만들거나 표시하지 않는다.
