# 정보주체 조회·동의 철회 점검

2026-10-04. P06-T05의 기본 구현과 이전 증거를 유지하면서 실제 PostgreSQL·HTTP 기준으로 보완한다.

1. 본인확인의 동일 202 응답·브라우저 연결·일회용 링크·고정 조회 범위와 철회 요청/취소/확정 모델을 확인한다.
2. DB 잠금 대기와 감사 저장 중 실제 세션/링크/보유기간 만료를 재현한다. 늦게 끝난 인증·조회·철회는 성공 자료나 감사·발송 차단 기록을 남기지 않도록 원자 롤백한다.
3. 동의/처리 이력의 현재 페이지와 엄격한 쿼리 검사를 화면·API 계약에 연결한다. 다른 세션의 요청, 정정 후 오래된 요청, 이미 완료된 요청과 재시도를 확인한다.

5. 현재 DB의 암호화 연락처·HMAC·동의 불변 이력·조회 범위·세션 종료·서비스별 suppression과 migration 체크섬을 독립 검사한다.
