## /sms — 발신번호 관리

- 상태 탭(전체·인증 대기·완료·만료·중지·삭제)·정렬 4종·검색·새로고침.
- 실데이터: "QA 미등록번호 01000001234 · 인증 대기"(발송 불가 고지)·"QA 솔라피 발신번호 01029062908 · 인증 완료 만료 2027-01-03 · 준비됨".
- 하단 고지: "문자 공급자에 등록된 번호의 활성 상태와 만료일을 확인합니다. 증빙 첨부만으로 발신번호 인증이 완료되지는 않습니다." — 원본 규칙 정직 반영.

## /sms/catchform·/sms/direct — 캠페인 작성

- 수집 자료 동의 대상 선택 / 연락처 직접 입력·CSV.
- 1단계 내용 작성: 캠페인 이름·발신자 검색/선택(미인증 "인증 필요"·승인 "사용 가능" 구분 표시)·발신자 등록·인증 관리 링크.
- 메시지 형식·제목·본문 + 변수 규칙 고지(`{{name}}`,`{{contact}}`·이름 없는 대상 제외·스크립트/이미지/스타일 제거·HTTPS·메일 링크만 허용)·정제 미리보기·초안 생성.

## /sms/history — 발송 내역

- 상태 필터(전체·초안·예약·처리 중·완료·일부 미발송·실패·취소·삭제·보관 종료)·기간·보관 필터·검색.
- 실데이터: 솔라피 라이브 캠페인 3건("처리 완료 · 접수·로컬 전달 1" 포함)·수신자 수·처리 결과·예약/생성 시각.
- 정직 고지: "공급자 접수는 발송 요청이 접수된 상태입니다… 외부 공급자 연결은 별도 확인이 필요합니다. 캠페인 내용과 연락처 사본은 생성 후 최대 30일 동안 보관합니다."
