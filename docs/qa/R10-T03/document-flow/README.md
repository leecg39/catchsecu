# 문서 공개 경로·편집·게시 수용 기록

2026-10-10. 로컬 production 서버와 Ego 공간 3에서 실행했다.

## 변경

유효한 동일 문서 토큰이 /document/view에서만 열리고 원본 P/C/OC 경로에서 실패하는 문제를 재현했다. 네 경로가 같은 토큰 검증 API를 사용하도록 연결했다. 접두사를 문서 유형에 대응시키는 추정은 하지 않았다. 실제 게시본·만료·회수 상태는 서버가 결정한다.

신규/기존 문서의 미저장 변경 이탈을 보호하고, 409 수정 충돌에서는 입력을 유지한 채 저장·게시·상태 변경을 잠근다. 최신 문서 재조회 전 입력 폐기를 확인한다. 게시 검증 자료가 아직 로딩 중인 상태에서도 게시 버튼을 비활성화했다.

## 실행 결과

- 문서·공개 접근·PDF·서비스 공개문서·경로 회귀 5파일 46개 통과. 전체 타입·변경 린트·production 빌드 통과.
- 실제 UI: 신규 입력 이탈 취소 → 초안 생성/목적 연결 → v1 게시/PDF → 동시 수정/409 → 재조회 취소/승인 → 수정/게시 v2 → v1 원문 유지 → 보관 → 네 경로에서 열람 거부 → 복원 → 기존 링크 계속 거부 → v3 재게시.
- 공개 API는 보관/복원 후 기존 링크에 410. 유효 링크는 P/C/OC/view에서 동일 내용. legacy-before/after.json, revoked-prefixes.json 참조.
- DB: 문서 version8·draftRevision3·게시본3개. v1은 최초 본문, v2/v3은 최종 본문. v1/v2 링크는 revoked, v3만 active. 목적120일·수탁자90일이 각 게시 스냅샷에 고정됨을 확인했다.
- 실제 다운로드 PDF 43,446바이트·1페이지. DB 바이트/해시 일치, 한글 제목·원문·기초 자료·120일/90일 텍스트 확인. 문서 업무 감사8건. db.json 참조.
- 390/768/1440px 편집·공개 화면의 가로 넘침 없음. 실제 390px 화면을 이미지로 보존했다.
- 서버 재시작 뒤 문서·게시본·공개 상태·PDF·감사 지문 일치. db-after-restart.json 참조.

PDF 검사 스크립트의 첫 실행은 PDF.js 6의 정리 메서드 변경으로 실패했다. installed 타입 선언에 맞춰 loading task의 destroy를 호출하도록 고친 후 타입과 실제 PDF 검증을 통과했다. 애플리케이션 PDF 생성 오류가 아니었다.

R10 전체 완료는 아니다. 문구 편집기 입력 보호/충돌, 처리방침·국외이전 문서의 전체 브라우저 흐름, 서비스 표시 연결과 전체 역할 수용은 계속 점검한다. 원본의 유료 정상 화면 미관찰 범위는 유지한다.
