[기존 증거 오프라인 재평가](../mock-completion/page-gate-prior-evidence.json)는 원본 해시를 기록했다. 12개 실제 미방문 경로 외에 `applicant/log` 경로1개는 두 매니페스트 패턴에 맞아 자동 연결이 모호하다. 새 브라우저 실행 결과가 아니다.
