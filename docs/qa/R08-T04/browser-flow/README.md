# 실제 폼 생성·게시·익명 응답

2026-10-10, 로컬 전용 회사·시험 응답자, Ego TaskSpace 3. UI에서 폼 생성, 이름 질문, 수집 목적, 보유기간 미지정 설정을 저장했다. 이름만 정보주체로 지정한 게시 요청은 거부됐으며 이메일 질문과 매핑을 추가한 뒤 게시됐다. 공유 URL로 로그아웃 상태에서 응답을 제출하고 관리자로 다시 로그인해 조회했다.

- 회사 기본 보유기간 365일, 활성 서비스 규칙 120일, 폼 지정기간 없음이라는 서로 다른 조건을 사용했다.
- 공개 화면·저장된 응답 기한·동의 영수증이 모두 120일을 사용했다. `db.json`은 복호화한 시험 답변, 정보주체 연결, 응답 수를 독립 DB에서 확인한 결과다.
- 게시 검증 거부는 `publish-validation.json`, 실제 제출은 `public-submission.json`과 캡처에 남겼다.
- 이후 같은 응답의 정정·메모·PDF·충돌 시험은 [R11 기록](../../R11-T04/browser-flow/README.md)에 이어진다. 따라서 이 디렉터리의 DB 기록은 최초 제출 시점의 상태다.

전체 질문 유형·템플릿·승인·첨부파일·본인인증 수용 완료를 뜻하지 않는다. 파일 검사는 별도 환경 복구 대기다.
