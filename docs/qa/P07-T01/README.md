## 변경

- 현재 회사·계정·역할·서비스·세션·MFA·비밀번호 정책을 잠그고 감사 저장 뒤에도 기한을 검사한다. 생성 캐시 저장 후 만료도 파일·작업·예약과 함께 롤백한다. 생성 재실행은 현재 작업 상태를 반환한다.
- 목록의 제목/ID 검색, 상태, 정렬, 페이지 보정을 적용했다. 미지원·중복 쿼리와 비표준 If-Match를 거절한다. 파일명이 만료된 경우 숨긴다. 미리보기와 실패 CSV는 감사 저장 후 보관 기한을 재검사하고, 연결 응답의 보유 기한에 맞춰 원문을 제외한다.
- `ImportJob.leaseGeneration`은 작업을 맡을 때마다 증가한다. 작업자 이름·실행 번호·현재 임대 기한이 일치하는 실행만 반영하거나 실패 상태를 저장한다. 새 DB 규칙은 임대 없는 응답·행 반영과 임의 실행 번호 변경을 거절한다.
- 원본 삭제 전에 반영자의 현재 권한을 검사한다. 원본 삭제 후 반영에 실패한 경우에도 삭제된 원본을 복원하지 않는다. 복구 실행은 남은 검증 행에서 재개한다.
- 화면은 서버가 계산한 수정·검증·반영·재시도·정리 권한, 지원하는 정렬과 보정 페이지를 사용한다. 업로드 재시도는 현재 파일 상태를 조회하여 이미 검사한 파일의 중복 업로드를 피한다.

## 보존 정책과 남은 게이트

원본과 임시 행은 최대 24시간 보관한다. 파일 내 동일 행은 중복으로 제외하고, 같은 작업의 재실행으로 응답을 추가하지 않는다. 별도로 등록한 새 CSV 작업은 별도 수집이다. 이미 반영된 응답·수집 증거는 응답의 보유 기한·보존 조치·파기 규칙을 따른다.

기존 회사·사용자 데이터는 별도 합성 회사의 HTTP 검증 전후 해시로 대조한다. 전역 처리기나 실제 인증 공급자를 실행하지 않는다. 이 테스트의 파일 저장소와 ClamAV 검증은 로컬 환경이다.

원본 사이트 현재 동작, 실제 화면 조작, 운영 저장소·백업 복구 후 삭제와 선행 작업의 남은 게이트를 확인해야 전체 Task를 완료할 수 있다. 이전 [CSV 검증](../imports/README.md)의 브라우저 자료는 이번 화면 수정의 증거로 사용하지 않는다.

Ego 재개 승인을 기다리고 있다. [ego-browser 스킬](/Users/user01/.agents/skills/ego-browser/SKILL.md:74)의 **“stop and ask the user”** 규칙에 따라 기존 창 재개 전에는 다른 창이나 브라우저로 우회하지 않는다.
