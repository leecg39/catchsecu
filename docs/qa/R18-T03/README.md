# R18-T03 — 발신메일·이메일 발송·수신거부: 전체 화면·모달 연결

실제 서버(localhost:3121)·실제 DB·로그인 세션에서 브라우저 검증.

| 경로 | 확인 내용 |
|---|---|
| `/mail` → 발신 주소 관리 | 목록: 인증 완료("로컬 검증" 라벨)·인증 대기("인증을 완료한 발신자만 사용할 수 있습니다") 구분, 상태·정렬·검색 필터, 페이지네이션, "이메일 인증번호와 도메인의 DNS TXT 값을 모두 확인" 안내 |
| `/mail/number` | 동일 발신 주소 관리 화면 정상 렌더 |
| `/mail/catchform` | 수집 자료 동의 대상 발송: 캠페인명, 인증된 발신자만 "사용 가능" 표시(대기 발신자 "인증 필요"), 텍스트/HTML 형식, `{{name}}`·`{{contact}}` 변수 안내, HTML 정제 규칙 안내, 수신거부 링크 자동 추가 고지, 초안 생성 |
| `/mail/direct` | 직접 입력·CSV 발송 동일 작성 화면 |
| `/mail/history` | 캠페인 목록: 상태(처리 완료/일부 미발송/초안), 수신자 수, "접수·로컬 전달 N · 제외 N" 정직한 로컬 결과, 기간·상태·보관 필터, "외부 공급자 연결은 별도 확인이 필요" 고지, 콘텐츠 보관 30일 고지 |
| `/mail/history?view=suppression` | 이메일 발송 차단: 수신거부·영구 반송 실제 행 4건, 사유 필터, "릴레이 설정 완료 · 외부 공급자 확인 전" 고지, 원문 삭제 후 비표시·재발송 방지 유지 설명 |
| `/mail/history?view=templates` | 메시지 템플릿 관리 탭 존재 |
| `/mail/catchform?campaignId=<id>` | 캠페인 상세: 발송 내용 스냅샷, 첨부(최대 5·각 10MB·합계 20MB 규칙), 수신자별 상태·사유·시도·수신 결과("수신 거부: 수신자 확인", "영구 반송: 서명된 릴레이"), 결과 CSV 다운로드, 예약·처리 관리, 버전 이력 v1~v5 |
| `/mail/no-mail` | 발신 주소 없음 게이트: 등록 안내 + 등록 페이지 이동 버튼 |

401/403은 빈 목록이 아닌 인증 게이트로 처리됨(비로그인 접근 시 로그인 리다이렉트, 타 테넌트 리소스 403은 API 수용에서 확인).
