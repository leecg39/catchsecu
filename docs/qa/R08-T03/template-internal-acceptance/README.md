# R08-T03 템플릿 내부 수용 체크포인트

2026-10-11 기준의 부분 검증 기록이다. 이 체크포인트만으로 R08-T03 또는 전체 목표를 완료 처리하지 않는다.

## 확인한 동작

- 실제 production 서버와 PostgreSQL에서 회사 템플릿을 생성했다.
- 빨간색 대표 이미지를 업로드하고 저장한 뒤 파란색 이미지로 교체했다.
- 템플릿 목록의 미리보기에서 교체된 파란색 이미지와 템플릿 내용을 확인했다.
- 교체 전 빨간색 자산은 템플릿 참조가 해제되고 만료 시각이 설정됐다.
- 교체 후 파란색 자산은 `template_thumbnail` 참조 하나를 가지며 만료 대상에서 제외됐다.
- 두 편집 탭으로 버전 충돌을 만들고 `409` 응답 뒤 현재 입력이 보존되는 것을 확인했다.
- 최신 서버 값을 적용하기 전에 입력 폐기 확인창이 표시되는 것을 확인했다.
- 대표 이미지 제거와 템플릿 삭제의 최종 확인 단계까지 진입했다.

Ego Lite 확장 탭은 로컬 파일 URL 접근이 꺼져 있어 파일 업로드가 차단됐다. 브라우저 설정을 바꾸지 않고 같은 로컬 서비스에 로그인한 격리된 인앱 브라우저에서 대표 이미지 수용을 진행했다.

## 승인 대기

브라우저 자동화 확인 정책 때문에 다음 최종 클릭은 사용자 확인 뒤에 실행한다.

1. 충돌 편집 탭에서 현재 입력을 폐기하고 최신 서버 값을 적용한다.
2. 파란색 대표 이미지 연결을 제거하고 저장한다.
3. 수용 검증용 템플릿을 영구 삭제한다.

이후 템플릿 부재, 파란색 자산 참조 해제와 만료 예약, `template.deleted` 감사 이벤트를 DB에서 다시 확인해야 한다. 외부 결제·구독 계정이 필요한 공용 템플릿 라이선스 검증도 별도 미완료 상태다.
