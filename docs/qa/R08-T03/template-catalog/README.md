- 썸네일 자산의 tenant/service/purpose 경계와 참조 pin을 DB 제약·트리거로 보호한다. 템플릿으로 폼을 만들 때 썸네일은 폼 콘텐츠 자산으로 복사하지 않는다.

## Ego Lite 브라우저 체크포인트

- 서비스 템플릿의 생성·편집·저장·새로고침, 일치/불일치 검색, 미리보기와 미저장 이동 보호를 실제 Ego Lite에서 확인했다.
- 만료된 체험만 있을 때 사용 거부를 확인했다. 제품 만료 워커로 기한이 지난 QA 구독을 정리하고 7일 로컬 체험을 만든 뒤 템플릿 사용과 폼 생성을 확인했다. 이 로컬 체험은 외부 결제 성공 증거가 아니다.
- 복제된 폼은 별도 폼·버전·문항 ID를 사용했다. 원본 템플릿을 다시 수정한 뒤에도 폼의 제목·본문·질문·동의·보유 설정은 복제 시점 값으로 유지됐다.
- 두 Ego Lite 탭에서 409를 재현했다. 첫 탭 입력이 보존되고 최신본 적용 안내가 표시됐으며, 확인창에서 `현재 입력 유지`를 선택해 입력 유지까지 확인했다.
- 목록이 열린 상태에서 production 서버를 중단해 연결 실패와 재시도 버튼을 확인했다. 같은 빌드를 재기동한 뒤 빈 검색 결과와 전체 목록이 복구됐다.
- 390·768·1440px에서 페이지 전체 가로 넘침이 없고, 390px 표는 내부 가로 스크롤을 제공하는 것을 확인했다. 검색·두 탭과 행 관리의 Tab 순서, 사용·삭제 대화상자의 포커스 트랩, 미리보기·사용·삭제의 Escape 닫기와 포커스 복귀를 확인했다.
- 격리 브라우저의 로컬 QA viewer 계정에서는 미리보기만 노출되고 생성·사용·편집·삭제가 숨겨졌다. 직접 편집 URL도 권한 오류로 차단됐다.
- 격리 브라우저의 B사 owner 계정에서는 A사 템플릿이 목록에 나타나지 않았고, A사 templateId 직접 접근도 찾을 수 없음으로 차단됐다.
- 격리 브라우저의 editor 계정에서는 생성·미리보기·사용·편집·삭제와 직접 편집을 확인했다. privacy 계정에서는 미리보기만 노출되고 직접 편집이 차단됐다.
- security 계정은 미리보기 전용, auditor·billing·sender는 목록 권한 오류와 재시도 버튼을 확인했다. admin·owner·editor·privacy·viewer를 포함한 로컬 역할 경계를 모두 확인했다.

구조화된 브라우저·DB 증거는 [browser-acceptance.json](browser-acceptance.json)에 기록했다.
