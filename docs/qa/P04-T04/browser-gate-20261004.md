## 검증 내역

### 목록·상태 표시
- `/form/manage`: 11건 표시 (archived 1건 "독립 복제 원본" 제외) — **DB 비보관 11건과 일치**
- 초안 행은 "초안" + 응답 "-", 게시 행은 "공개 중" + "n / 한도" — 상태별 렌더 분리
- 초안 행 액션: 미리보기/편집/템플릿 등록/복사/보관/완전 삭제 (공유·일시 중지 없음)
- 게시 행 액션: 미리보기/편집/템플릿 등록/복사/공유/일시 중지/보관/완전 삭제 — **상태별 액션 차등**
- 신규/편집 구분: "캐치폼 생성" → `/form/ai/create?new=1`, 행 "편집" → `?formId=<id>` — 경로 수준 혼동 없음
- 즐겨찾기 토글: 11번 행 "독립 복제 원본 (복사) 즐겨찾기" pressed 상태 렌더

### 페이지네이션·범위 보정
- 페이지 크기 10 선택 → 총 11건이 "1 / 2"로 분할, 다음 페이지 활성
- 2페이지 이동 → 11번째 행만 표시, 이전 활성·다음 비활성
- **2페이지 상태에서 "독립" 검색 → 결과 1건으로 자동 1페이지 복귀** (빈 페이지 범위 보정 동작)

### 참조 중 삭제 불가 (수용 조건 핵심)
- "독립 복제 원본 (복사)" (게시 이력 + 응답 1건 보유) → "완전 삭제" 클릭
- 모달 "캐치폼 완전 삭제" 표시:
  - "…질문·초안·즐겨찾기를 영구 삭제합니다. 감사 기록은 유지되며 삭제한 내용을 복구할 수 없습니다."
  - **"게시 이력이 있어 기존 공개·수집 증거를 유지해야 합니다. 보관할 수 있습니다."**
  - **"수집한 응답이 있습니다. 응답 화면에서 파기 요청을 관리해주세요."** + 응답 관리 링크
  - **"완전 삭제" 버튼 disabled** — 참조 중 삭제 불가
  - "삭제 조건 다시 확인" 버튼 제공
