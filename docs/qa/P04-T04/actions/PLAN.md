# P04-T04 현재 서비스 권한과 작업 안내 보완

2026-10-03. 이전 회차의 583개·54개 기록을 유지하고 후속 소스/검증은 이 폴더에 저장한다.

## 현재 코드에서 확인한 누락

폼 목록은 Application의 역할 전체 capabilities로 편집/복사/공유/보관/삭제와 생성/업로드 버튼을 표시한다. 응답 링크도 모든 역할에 표시한다. 개별 서비스 grant·현재 서비스 보관 상태·공개 링크 만료는 버튼에 반영되지 않는다. 실제 변경 API는 현재 권한을 검사해 거부하지만 화면은 실행할 수 없는 작업을 안내한다.

## 구현

1. 현재 계정/세션/구성원/전문가/서비스를 검사하는 목록·상세 GET DTO에 작업별 권한/상태를 반환한다. 생성/저장/복사/템플릿의 멱등 재전송 응답에는 작업 권한을 캐시하지 않는다.
2. 목록 메타데이터에서 선택 서비스의 폼 생성, 업로드 생성/목록 권한을 계산한다. 미선택 목록은 현재 조회 가능한 서비스 중 해당 권한이 있는 범위를 확인한다.
3. 미리보기·응답·편집·복사·템플릿 등록·공유·중단/재개·보관·삭제 조건 조회를 현재 DTO로 표시한다. 응답 권한이 없는 제목은 미리보기로 연결한다. 참조된 폼의 삭제 조건 조회는 계속 허용해 사유를 확인할 수 있게 한다.
4. 삭제 조건 DTO에서 현재 응답 조회 권한을 반환해 파기 관리 링크도 현재 권한을 따른다. 보관된 서비스·가져오기 양식의 변경 작업은 안내하지 않는다.
5. 실제 PostgreSQL에서 서비스 grant·역할·상태·만료·과거 Context와 해당 변경 API의 결과를 비교한다. production 서버에서 권한별 실제 응답·상태와 재시작 후 DB를 대조한다.
6. 타입·린트·빌드·전체 회귀·계약/계획과 소스 해시를 확인한다. 브라우저 조작/정상 원본·선행 게이트는 남은 상태로 기록한다.
