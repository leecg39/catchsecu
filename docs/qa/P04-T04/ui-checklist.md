# P04-T04 실제 화면 검증 — 실행 대기

기존 Ego 창의 제어 재개 응답 후 합성 시험 회사에서 desktop과 390px 화면을 조작한다. PostgreSQL/API 결과는 이 화면 검증을 대신하지 않는다.

| 화면 | 조작·확인 |
|---|---|
| 목록·검색 | 제목/생성자 검색, 한국 날짜 기간, 상태/보관 포함, 즐겨찾기, 정렬 기준/순서, 페이지 크기 |
| 페이지 보정 | 두 페이지에서 검색 후 page=1, 마지막 행 삭제 뒤 마지막 페이지, 빈 결과의 첫 페이지 표시와 버튼 |
| 생성·편집 | 신규 생성과 formId 편집의 구분, 같은 ID 유지, 저장 중 이동/재전송, 보관한 폼의 편집 제한 |
| 미리보기 | 최신 초안/게시 버전 표시, 본문·선택지·행렬 행·조건·선택 수, 동의서·표시 문구·보유 기간 |
| 복사 | 독립 ID/질문 ID, 네트워크 결과 유실 후 같은 키 재시도, 원본 삭제 뒤 복사본 유지 |
| 서비스별 작업 권한 | 조회자·편집자·개인정보 담당자의 제목 링크/미리보기와 작업 버튼, 선택 서비스의 생성·업로드/목록, 역할·grant 회수 후 서버 오류와 목록 갱신 |
| 보관·만료 | 보관한 서비스/폼 및 가져오기 양식의 변경 버튼, 만료된 공개 링크의 공유·재개, 삭제 조건과 응답 링크의 서로 다른 권한 |
| 복사 재시도 범위 | A 복사 결과 유실→B 복사→A 재시도에서 A의 키 유지, 성공 후 새 복사는 새 키, 폼별 독립 복사본 수를 DB로 대조 |
| 공개 상태·보관 | 일시 중지/재개, 공개 종료와 보관 안내, 기존 응답·게시/승인 기록 유지 |
| 완전 삭제 | 서버 삭제 조건과 version, 확인 체크박스, 삭제 후 목록 갱신, 복구 불가·감사 보존 안내 |
| 참조·오류 | 게시/승인/응답/공유/업로드/파일 사유, 응답 파기 요청 이동, 권한/회사 범위, 409 후 조건 다시 확인, 모달 내부 오류 |
| 390px·키보드 | 정렬·검색·테이블/페이지·미리보기·삭제 모달의 읽기/입력/동작, 가로 넘침, Tab·Escape |

정상 원본의 경로·목록·상태/삭제 안내와 차이를 기록한다. 사례마다 캡처와 실제 formId/version, 독립 DB 대조를 남긴다. 선행 P04-T03의 정상 원본·브라우저·다른 선행 게이트와 본 작업의 전체 수용 조건이 갖춰질 때 완료로 집계한다.
