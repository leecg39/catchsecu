# P04-T05 실제 화면 검증 — 대기

Ego의 기존 TaskSpace 34 제어가 명시적으로 재개된 뒤 실행한다. 현재 API/DB·소스 검증은 실제 렌더링·입력/키보드 검증을 대신하지 않는다.

| 흐름 | 확인할 동작 |
|---|---|
| 생성·초안 | 현재 작성 가능한 활성 서비스만 선택, 같은 ID 저장/이동/재접속, 결과를 알 수 없는 생성/저장 재시도 |
| 양식 등록 | 원본 폼 제목·본문·아홉 질문·행·분기·동의/서비스 초기값, 공개 양식 읽기와 서비스 양식 수정/삭제 구분 |
| 목록·사용 | 두 페이지 검색·빈/마지막 보정, 현재 서비스/역할 버튼, 타 서비스 제한, 생성 대상 목록, 상세 미리보기 재조회 |
| 재시도 | A 사용 응답 유실→닫기→B 사용→A 재시도에서 양식/payload별 키 유지, 성공 뒤 새 사용 키, DB 독립 폼 수 |
| 아홉 유형 | 질문 순서·조건·행·최소/최대 선택·날짜·파일 업로드 상태/오류·필수/선택 동의, 숨긴 필드 정정 |
| 승인·게시 | 요청·반려·재요청·승인·버전 충돌, 권한 회수 후 버튼/실제 오류, 새 버전 전후 공개/고정 주소/응답 증거 |
| 공유 | 현재 게시 링크와 만료, 응답 항목 선택·초대·인증·선택 범위와 파일·회수, 실제 제공자 검증의 별도 증거 |
| 삭제·보관 | 양식 삭제 후 독립 폼 보존, 과거 생성/사용 키 종료, 폼 보관/참조 삭제 안내, 감사 유지 |
| desktop·390px | 입력·모달·행렬·테이블 가로 범위, Tab/Escape, 이동/저장 중 동작, 브라우저 저장소 초기화 후 DB 복원 |

사례마다 캡처·실제 ID/version·서버 응답·독립 DB 대조를 기록한다. 정상 원본과 차이, 선행 P04-T04·P06-T02 및 외부 연동·경합·재시작의 전체 수용 조건이 충족되어야 완료로 집계한다.
# 단계별 권한 보강 후 추가 확인

- [ ] 작성 전용 서비스는 저장이 가능하고 게시 버튼은 차단한다.
- [ ] 게시 전용 서비스는 설정을 조회하며 저장된 초안을 게시한다. 작성 PATCH 요청을 보내지 않는다.
- [ ] 역할/서비스 권한 회수 후 창 재활성화·15초 재조회에서 버튼을 갱신하고 이미 입력한 내용은 유지한다.
- [ ] 초안이 없는 게시 폼은 공유로 이동하고, 새 변경의 저장 후에는 최신 게시 권한과 version을 확인한다.
- [ ] 성공 응답 유실·전송 유실·중복 클릭 후 게시가 한 번만 반영되고 최신 공유 상태를 표시한다.
- [ ] 보관·만료·권한 회수 뒤 공유 주소와 응답 버튼을 현재 권한에 맞춰 표시한다.
