# P04-T05 폼 모듈 통합 검증 — 진행 중

2026-10-04. [계획](PLAN.md)에 따라 템플릿과 단계별 작성/게시 권한, 아홉 질문·필수 파일·OTP의 결합 흐름을 보완했다. 최신 [통합 경합·영수증 검증](concurrency/README.md)은 전체 회귀 **46파일·614개**, 실제 API **67개(51+16)**가 통과했다. 이전 Workflow API 103개와 템플릿 API 56개는 각 단계의 증거로 유지한다. 선행 P04-T04·P06-T02와 실제 브라우저·정상 원본·외부 연동 검증이 남아 공식 완료는 15/72다.

## 구현과 PostgreSQL 증거

- 템플릿 목록은 transaction 안에서 현재 회사·구성원·역할·grant·계정/이메일 인증·세션·전문가 배정과 만료를 확인한다. 배정 외 여분 grant를 제외하고 전문가의 보관 서비스 목록·상세를 숨긴다. 직접 구성원의 보관 서비스 읽기는 유지한다.
- 회사/공용·검색·생성일/제목 정렬·마지막/빈 페이지를 서버에서 처리하고 알 수 없는 입력은 422로 거부한다. GET에는 현재 편집·삭제·사용 권한과 활성 생성 대상 서비스를 반환한다. 생성/수정/사용 응답에는 작업 권한을 캐시하지 않는다.
- 화면은 현재 DTO의 작업과 생성 대상으로 버튼·선택지를 표시하고 미리보기 때 상세를 다시 조회한다. 사용 재시도 키는 양식과 payload별로 유지한다. 편집기는 활성 작성 대상과 GET 작업 권한을 확인하고, 폼에서 양식 등록을 시작하면 원본 제목·내용·서비스를 초기값으로 사용한다. 실제 렌더링·입력·재시도 확인은 남아 있다.
- 템플릿 삭제는 version과 현재 권한을 검사한 뒤 신규 캐시와 회사 구성원 범위의 이전 생성 캐시 내용·요청 해시를 같은 transaction에서 지운다. 생성 키 재전송은 410이고 독립 폼·다른 템플릿/캐시·감사는 유지한다. 모델/migration 추가는 없다.

권한/목록 테스트 첫 실행은 본문 필수값이 빠진 fixture로 멈췄다. 이를 보완한 다음 8개 중 실제 제품 실패 6개와 전문가 fixture 오류 2개를 구분했다. 전문가 배정 서비스는 별도 relation 생성으로, 회사 상태는 DB의 `suspended` 값으로 보완했다. 최종 권한/목록 8개가 통과했다. 이어서 삭제 후 생성 재전송이 **201**을 반환하는 실패를 재현해 고쳤다. 신규/이전 캐시 제거·오래된 version 실패 시 보존·다른 양식 캐시 유지·410을 함께 검사했다. 생성 캐시 테스트를 포함한 템플릿 검증은 9개다.

별도 통합 테스트 1개는 아홉 유형의 생성→같은 ID 초안 저장→양식 등록/멱등 사용→독립 질문·행·분기 복제→원본 양식 삭제→게시된 동의서 연결→반려/재요청/승인→게시→고정 주소→파일 응답→공유 권한 생성→새 버전/재승인/재게시→중단/재개/보관을 확인한다. 실제 ClamAV 검사와 다운로드 바이트, 조건에 숨긴 응답·초과 선택 수·필수 문서 동의 422와 실패 시 파일 권한 보존을 확인했다. 이전 게시 버전·암호화 응답·공유 버전·첨부를 새 게시/보관 후에도 비교했다. 초기 공유 route import 오류는 제품 실패로 집계하지 않는다. 최종 **2파일·10개**가 통과했다.

## 실제 production API

템플릿 보강 단계의 API **56개(준비 40개·재시작 후 16개)**가 통과했다. 별도 합성 회사·두 서비스에서 아홉 유형 양식 CRUD, 두 페이지/검색·범위 보정, 할당 범위 403, 같은 세션 역할 회수·복구, 작업/대상 DTO, 독립 폼의 질문/행/분기, 같은 사용 키, 오래된 양식 수정 409, 게시·공개 응답·보관·삭제 뒤 폼 보존, 삭제한 양식의 생성 키 410을 확인했다.

Production 응답은 파일 질문을 선택으로 두고 첨부 없이 제출했다. 실제 파일 업로드·검사·다운로드 및 동의/승인/공유의 전체 결합은 위 PostgreSQL 테스트에서 확인했다. 이 API 기록을 production의 첨부·OTP 공유 열람·전체 승인 흐름 증거로 사용하지 않는다. 초대는 local 설정의 해당 합성 회사 큐 한 건만 읽어 수락했고 외부 전송이나 전체 worker를 실행하지 않았다. 합성 세션을 종료했으며 사용자 관리자 계정은 변경하지 않았다.
