# P09-T04 알림톡 발송·수신 결과

## 개요

승인 완료된 카카오 알림톡 템플릿 기반 발송, 수신자별 치환 변수 검증, 예약/즉시 발송, 발송 실패 시 SMS 대체 발송(Fallback) 정책을 구현한다.

## 구현 내용

1. **알림톡 발송 엔진**:
   - `POST /api/v1/kakao/templates/[id]/send`: 알림톡 발송 요청
   - 채널 인증 상태 및 템플릿 승인 상태(`approved`) 교차 검증
   - 수신자별 치환 변수 누락 여부 사전 검증
2. **실패 대체 발송 (Fallback SMS)**:
   - 카카오톡 미설치자 또는 발송 실패 건에 대해 사전에 지정된 SMS 발신번호로 자동 대체 전송
   - 대체 발송 중복 과금 방지 및 원장 차감 연동

## 검증 내역

- 테스트 스위트: `tests/server/kakao-templates.test.ts`, `tests/server/campaigns.test.ts`
- 주요 검증 항목:
  - 채널/템플릿 미인증 상태에서의 발송 시도 차단 (503/409)
  - 변수 누락 요청 422 거부
  - 대체 발송 시 SMS 어댑터 큐잉 및 영수증 연계
