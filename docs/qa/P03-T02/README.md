## 2026-10-03 구성원 게이트 보완

- 만료 초대 재발송·정지 구성원 복구·신규 전문가 배정은 활성 구성원과 다른 대기 초대의 좌석 예약을 함께 확인한다. 재발송과 수락은 자기 초대의 예약을 제외해 이중 계산하지 않는다. 유효한 초대 링크라도 구독이 만료되면 재발송은 402다.
- 구성원의 서비스 범위는 빈 배열로 모두 회수할 수 있다. 기존 세션의 선택한 서비스를 해제하고 직접 URL·목록을 다음 요청부터 차단한다. 가입 초대는 최소 한 서비스가 필요하다.
- 회사 잠금 뒤 구성원 관리자의 실제 계정 상태를 재검사한다. 초대 수락은 계정·인증 이메일·살아 있는 세션을 다시 확인해 정지 계정과 폐기된 세션의 초대 소비를 막는다.
- 전문가 본인 회사 검색을 서버의 전체 배정에 적용하고 회사 선택 화면에 페이지 이동을 연결했다. 구성원·배정 양식의 중복 요청과 전송 중 닫기를 막았다.
- 회사 목록 GET은 실제 활성 소속 회사만 검색·페이지 조회하며 관리자 외 사용자에게 파일·폐쇄 사유를 공개하지 않는다. 회사 문서·폐쇄 API와 최신 필드도 OpenAPI 생성기에 반영했다.
- worker는 초대 전달 전에 회사 잠금 아래 현재 버전·기한·상태·수신 이메일·초대 담당자 권한과 서비스 상태를 확인한다. 만료·취소·옛 버전의 메일은 전달하지 않는다.
