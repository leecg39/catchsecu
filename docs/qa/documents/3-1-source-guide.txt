      캐치폼 동의서의 경우 캐치폼 생성 시 자동으로 생성되는 개인정보 수집·이용 동의서입니다
      일반 동의서의 경우 ‘동의서 생성’ 페이지를 통해 생성되는 동의서입니다.
동의서 내용 수정하기
캐치시큐 대시보드에 동의서&처리방침 > 동의서 목록을 클릭해 주세요
수정하고자 하는 동의서의 우측에 관리 > 내용수정을 클릭해 주세요.




내용을 수정 후 ‘개인정보 처리 목적 수정’ 버튼을 클릭해 주세요.




동의서 설명 수정하기
캐치시큐 대시보드에 동의서&처리방침 > 동의서 목록을 클릭해 주세요
수정하고자 하는 동의서의 우측에 관리 > 설명수정을 클릭해 주세요.




수정하고자 하는 내용을 수정 후 ‘적용하기’ 버튼을 클릭해 주세요.




페이지 하단에 ‘저장하기’ 버튼을 클릭해 주세요.




동의서 공유하기
캐치시큐 대시보드에 동의서&처리방침 > 동의서 목록을 클릭해 주세요
공유하고자 하는 동의서 항목의 우측에 관리 > 공유하기를 클릭해 주세요
복사된 URL을 적용이 필요한 곳에 붙여넣기 해주세요.




동의서 삭제하기
캐치시큐 대시보드에 동의서&처리방침 > 동의서 목록을 클릭해 주세요
공유하고자 하는 동의서 항목의 우측에 관리 > 삭제하기를 클릭해 주세요.




문구를 그대로 입력 후 ‘삭제’ 버튼을 클릭하면 동의서가 삭제됩니다
  삭제된 동의서는 복구할 수 없습니다.




동의서 영문버전 생성하기
캐치시큐 대시보드에 동의서&처리방침 > 동의서 목록을 클릭해 주세요
번역하고자 하는 동의서 항목의 우측에 관리 > 영문버전을 클릭해 주세요.




‘영문 버전 생성하기’ 버튼을 클릭해 주세요.




개인정보 보호 전문가 가이드
캐치시큐 대시보드에 동의서&처리방침 > 동의서 목록을 클릭해 주세요
우측 단의 ‘전문가 가이드’ 버튼을 클릭해 주세요.
