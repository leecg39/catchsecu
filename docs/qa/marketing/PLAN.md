# P07-T02 마케팅 동의·차단 목록 구현 계획

## 확인한 원본
- `docs/research/forms/form_ad-manage.json`: 이름, 이메일, 전화번호, 수집 출처, 동의일·철회일, 이메일·문자 발송 제외, 선택 철회.
- `docs/research/public/_marketing-detail.json`: 회사 전체와 서비스별 동의·철회 현황.
- 원본의 빈 목록 외 세부 상태 전이는 확인되지 않았다. 아래는 독립 구현의 명시적 계약이며, 원본 서버 동작을 확인했다고 간주하지 않는다.

## 1. 데이터와 동의 근거
- [x] `MarketingPreference`: 회사·서비스·채널(email/sms)·정규화 연락처 HMAC 유일. 이름/연락처/동의 근거는 암호화. 원본 응답, 이름/연락처 질문 ID, 동의 시각, 상태(granted/withdrawn/erased), 발송 제외, 낙관적 버전 저장.
- [x] 이메일 기반 DataSubject를 전화번호만 있는 응답에 억지로 연결하지 않는다. MarketingPreference는 같은 회사·서비스의 Submission으로 출처를 보장한다.
- [x] `MarketingEvent`: 생성·재동의·제외·제외 해제·철회·삭제·출처 무효화의 변경 이력. 자유 입력 개인정보를 이력·감사 로그에 복제하지 않는다.
- [x] 기존 개인정보 동의·필드 제목·예전 marketingConsent boolean으로 수신동의를 추론하지 않는다.
- [x] 폼에 별도 마케팅 목적과 이름/채널별 연락처 질문을 명시한다. 공개 폼에서 채널별 선택 동의를 받고 서버 시각·게시 버전의 문구를 증거로 남긴다. 기본값은 미선택이다.
- [x] 기존 폼/CSV 응답은 관리자가 원본 질문을 선택하고 동의 시각·목적·증빙 참조를 명시해야 등록할 수 있다. 일반 수집동의만으로 일괄 opt-in을 생성하지 않는다.

## 2. API와 권한
- [x] 전용 marketing.read/write 권한. 개인정보 관리자에게 읽기·쓰기, 발송 담당자에게 읽기만. 역할과 현재 서비스 권한을 트랜잭션에서 다시 검사한다.
- [x] 목록/상세/이력, 응답 출처 선택, 생성, 발송 제외 수정, 개별·일괄 철회, 삭제(연락처·근거 원문 제거), CSV 내보내기, 서비스별 통계.
- [x] 서버 페이지 처리, 채널/상태/제외 필터, 암호화 필드의 정규화 완전일치 검색, 동일 필터 CSV(상한과 수식 무해화).
- [x] 등록은 요청 키로 중복 방지. 변경은 버전 검사. 일괄 철회는 최대 100개 원자 처리, 동일 요청의 반복 철회는 중복 이력 없음.
- [x] 재동의는 철회 이후의 새로운 명시적 근거만 허용. 발송 제외와 기존 정보주체 철회 차단은 재동의로 해제하지 않는다.

## 3. 수명주기와 발송
- [x] 응답 철회 시 해당 마케팅 동의도 철회. 정정으로 이름/연락처가 바뀌면 기존 동의를 새 연락처로 이전하지 않는다.
- [x] 원본 응답의 파기·기한 만료 시 조회/발송 차단, 파기 완료 시 마케팅 연락처·근거 원문도 제거. 최소 HMAC/상태/이력만 보존.
- [x] 이메일 큐 등록과 실제 worker 전달 직전에 현재 동의·제외·원본 응답·보유기한·서비스·기존 suppression을 다시 검사한다. 동의가 변경되면 예약된 이전 버전 발송은 취소한다.
- [x] 동일한 채널 판정 함수를 SMS 어댑터가 사용할 수 있게 제공하고, SMS 실제 공급자 구현/외부 수신 검증은 P08 단계에서 이어간다.
- [x] 발송/철회/정정/파기가 경합할 때 응답 잠금 → 채널 연락처 잠금 순서를 지킨다.

## 4. 화면
- [x] `/form/ad-manage`: 출처 기반 등록, 검색·필터·페이지 이동, 상세·근거·이력, 제외 설정, 개별/선택 철회, 삭제 확인, CSV.
- [x] FormEditor와 PublicForm의 선택 마케팅 동의 설정/입력.
- [x] `/marketing-detail`: DB 집계 기반 서비스별 현황, 현재 0도 그대로 표시.
- [x] 로딩·빈 상태·서버 오류·권한 거부·버전 충돌과 모바일 가로폭 점검.

## 5. 검증과 증거
- [x] PostgreSQL: 교차 회사/서비스 거부, 입력 검증, DB 제약, 선택 동의, 재동의 근거, 검색·pagination·CSV, 중복 생성/철회, 버전·권한 경합, 정정·철회·파기·기한 만료.
- [x] worker: 허용된 합성 로컬 메일 전달, 큐 등록 후 철회/제외/기한 변경/삭제에 따른 전달 차단, 인증메일의 별도 경로, 이메일/SMS 채널 격리.
- [x] Ego Space30/p1: 실제 화면 등록→읽기→제외 변경→철회→삭제, 폼의 선택 동의 수집, 새로고침/재시작 영속성, 내보내기·통계.
- [x] 전체 회귀 테스트, 타입 검사, 린트, production build와 계획 검증. 원본 미확인 사항·외부 공급자 미검증을 문서에 남긴다.
