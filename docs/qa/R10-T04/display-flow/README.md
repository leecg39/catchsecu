# 서비스 동의서 표시 설정·문구·처리방침 연결

2026-10-10. Ego Lite 실제 화면·localhost HTTP·PostgreSQL을 대조했다.

## 구현과 실제 흐름

탭을 바꾸면 미저장 표시 설정이 사라지는 현상을 [재현](unsaved-before.json)했다. 서비스·동의서 종류 전환과 페이지 이동에 입력 보호를 추가했다. 409 이후 최신 설정을 불러오기 전에도 입력 취소 확인을 거친다. 요청 처리 중에는 서비스·탭 전환을 막는다.

1. 수집·이용 표시 설정에 내부 처리방침을 연결했다. 탭 전환 취소 시 입력 유지, 다른 작성자의 동시 수정으로 발생한409, 최신 설정 불러오기 취소/확인, 수정 재저장을 확인했다. [연결·충돌 증거](linked.json).
2. 연결된 처리방침 회수 요청을 UI에서 차단하고 반복 확인 버튼을 잠갔다. 최신 문서 재조회로 복구한다. [연결 중 회수 거부](revoke-in-use.json).
3. 표시 설정에서 연결 해제 후 링크를 회수했다. 이전 공개 링크410과 새 게시본 생성 후 재연결을 확인했다. [연결 해제](unlinked.json).
4. 제3자 제공 표시 설정을 별도로 생성해 HTTPS 외부 링크를 저장하고, 링크 없음을 선택해 주소·게시본 참조가 지워지는 것을 확인했다. 외부 예제 주소로는 이동하지 않았다. [외부 링크](external.json), [최종 설정](final.json).

## 검증 결과

- [HTTP·DB 대조](verified.json):29개 HTTP 검사 통과. 익명401, 미부여 viewer403, 다른회사 접근 거부, 오래된 개정409, 잘못된 URL·회사 필드 주입422. 문구6·문서5·수집표시설정5·제3자표시설정2 개정 및 감사18건을 독립 DB로 대조했다.
- 문구를 나중에 수정해도 이미 적용한 문서·게시 스냅샷이 바뀌지 않는다. 회수한 게시본1은 닫혀 있고 게시본2는 활성이다.
- [서버 재시작 후 HTTP·DB](verified-after-restart.json)와 [브라우저 재조회](browser-after-restart.json). 상태 해시가 재시작 전후 동일하고 저장한 처리방침 링크가 열린다.
- [390/768/1440px 폭](responsive.json), [390px 실제 화면](display-390.png). 페이지 전체 가로 넘침이 없고 동의서 종류 탭은 가로 스크롤로 접근한다.
- 새 production 빌드 및 변경 소스·검증 스크립트의 lint/type 검사 통과. 문서 관련 기존 서버 회귀34개 통과는 [문구 검증](../../R10-T03/clause-flow/tests.json)에 보존했다.

이 검증은 현재 로컬 범위다. 국외이전 유형의 실제 UI 흐름, 모든 원본 파생 경로, 전체 역할·운영 정책 수용은 후속 작업으로 남아 있다.
