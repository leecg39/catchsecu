# 국외이전 문서의 실제 화면·DB·공개 조회 검증

2026-10-10. Ego Lite 공간3과 로컬 `catchsecu_dev`에서 합성 자료로 수행했다. 원본 서비스 자료를 변경하지 않았다.

1. 국외 수탁자(US·45일·이름/이메일·연락처·이전 방법/시기·거부 안내)를 화면에서 생성했다.
2. 국외 수탁자가 없는 국외이전 초안은 게시 불가를 확인했다. US 수탁자를 연결하고 저장→v1 게시했다.
3. 초안에서 US 수탁자를 해제해도 v1 공개 수탁자·국가 필터와 본문은 유지됐다. 불완전한 초안은 새 게시가 차단됐다.
4. US 수탁자를 다시 연결하고 본문을 수정하여 v2를 게시했다. v1/v2 PDF를 실제 버튼으로 다운로드했다.
5. 비공개 전환 시 두 공개 링크가410으로 닫혔다. 보관→직접 주소 재조회 시 읽기 전용→초안 복원→v3 재게시까지 화면으로 수행했다. 이전 링크는 계속 닫혀 있다.
6. 수집/필수/수탁/국외/고유식별정보 공개 안내7경로를 확인했다. `/document/view|P|C|OC/<token>` 4경로도 같은 v3 본문을 보인다. 고유식별정보가 없는 이번 서비스의 해당 목록은 빈 상태다.
7. 편집·공개 문서의390/768/1440폭을 측정했고 페이지 가로넘침이 없다. 390폭 캡처를 시각 검토했다.
8. 실제 HTTP30개에서 익명401·제한역할403·다른회사404·낡은버전409·잘못된입력422와 공개 필터를 확인했다.
9. 독립 DB에서 문서 개정10·초안개정4·게시3본·고정 수탁자 관계6건·감사10건을 확인했다. PDF3개의 다운로드 바이트/DB 바이트/SHA-256이 같고 한글·기간·이전방법을 확인했다.
10. 서버를 새 프로세스로 재시작한 뒤 동일 HTTP/DB/PDF 검사와 공개 화면 재로딩을 확인했다. 상태 지문은 `e764dc9efc9ca03519a2d553aa0f32df62f3f742ff87a190fb850548957c44a3`로 같다.
