# 첨부파일 권한·만료 점검

2026-10-04. P06-T03은 진행 중이다. 공개 제출과 파일 저장 기반의 정식 선행 게이트, 정상 원본 대조 및 Ego 검증까지 충족한 뒤 완료를 판정한다.

1. 실제 PostgreSQL과 ClamAV로 공개 파일을 업로드하고 응답·질문에 연결한다. 로그아웃·세션 만료·이메일 인증 회수·회사 선택 변경·회사 보안 정책을 기존 Context에 적용해 재검사한다.
2. 사용자/세션 변경과 파일 잠금을 별도 DB 연결에서 유지한다. 요청이 실제로 잠금을 기다리는지 확인한 뒤 회수 상태 또는 실제 만료를 반영한다. 저장소·감사 처리 지연도 실제 파일 I/O와 DB 트랜잭션으로 재현한다.
3. 로그인 사용자의 파일 경로와 작업/외부 공유 발급자의 검사 함수를 구분한다. 현재 권한을 잠금 아래 확인하며, 파일 응답 전 실제 기한을 다시 확인한다. 응답·질문·파일 조합과 중복/알 수 없는 쿼리를 거부한다.
4. 관련 테스트·전체 회귀·타입·린트·production 빌드 후 독립 합성 계정에서 실제 HTTP로 공개 첨부, 개인/공유 열람, 이름 변경·버전 충돌·실제 삭제·회수·시간 만료·재시작을 검증한다. 업무 해시와 기존 원본이 같은지 별도 DB 조회로 대조한다.

현재 중단된 Ego TaskSpace 34의 재개 승인은 별도 대기 중이다. 이번 점검에서 브라우저를 호출하거나 다른 브라우저로 우회하지 않는다. 네 file-view 주소의 HTTP 응답은 UI 조작 검증으로 집계하지 않는다. 전역 worker를 실행하지 않고 내보내기 전용 worker만 유지한다. 외부 S3와 본인인증 공급자 증거는 로컬 성공으로 대신하지 않는다.
