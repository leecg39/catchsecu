# 다음 구현과 시간 추정

2026-10-04 현재 공식 완료 15/72, 진행 19, 계획 38이다. 이 숫자는 외부·화면·운영 수용 조건까지 충족한 작업만 완료로 센다.

## 먼저 대조할 범위

- 계약에는 377개 작업 중 325개 구현, 52개 계획이 표시돼 있다. 계약 표시만으로 실제 미구현 개수를 확정하지 않는다.
- `/audit-events`에는 실제 GET 처리기와 서버 조회가 있다. `/admin/notices`, `/admin/guides`의 운영자 기능은 현재 `/notices`, `/guides` 처리기에 들어 있다. `/feedback` 관련 문의·제안 기능은 `/support-tickets`에 있다. 기존 코드와 계획 계약의 주소·역할·상태 전이를 대조해 중복 구현을 피한다.
- IP 규칙은 Prisma 모델만 확인되며 현재 API/화면 집행 경로가 없다. 카카오 화면은 정적 미리보기가 남아 있다. 이 영역의 모델·권한·CRUD·화면을 우선 대조한다.
- 보유 규칙, 유료 상품/결제/환불, SSO 설정과 실제 로그인, 사용량·월마감은 부분 구현과 미구현을 나눠 작업한다. 공급자 성공·심사·결제 승인 상태를 임의로 만들지 않는다.

## 실행 방식

1. 각 영역을 기존 모델/API/화면과 한 번 대조하고 실제 빈 기능부터 구현한다.
2. 변경 기능의 권한·CRUD·상태 전이·실제 저장/조회/삭제를 검증한다. 통과한 동일 입력의 검사를 새 변경·실패·미해결 우려 없이 반복하지 않는다.
3. 전체 회귀는 영역 통합과 출시 시점에 실행한다. 증거 문서는 결과·재현 방법·남은 조건만 기록한다.
4. 공급자 계정과 시험 환경이 필요한 항목은 기다리는 동안 다른 내부 구현을 진행한다.

남은 코드·로컬 검증의 거친 추정은 실작업 2~4일이다. 전체 미구현 대조 전 추정으로 오차가 크며, 전체 완료일 확약은 아니다. 외부 계정·심사·테스트 환경 준비에 걸리는 시간은 포함하지 않는다.
