# P08-T01 자체 점검

| 확인한 문제 | 수정 | 실제 검증 |
|---|---|---|
| 감사/캐시/잠금 뒤 로그인 기한 검사 누락 | 현재 권한의 기한을 보존하고 마지막 비동기 처리 뒤 검사 | PostgreSQL 감사 10종·캐시 지연·Company/Sender 잠금 |
| 생성 캐시에 이전 버전·삭제 결과 유지 | 최신 버전/현재 권한 반환·삭제 410 | 수정 뒤 재실행·삭제 뒤 재실행 |
| SQL 롤백 전에 인증 파일 삭제 | 확정된 큐 원문 삭제 뒤 물리 정리·지속 실패 기록 | 실제 파일 바이트 보존·디렉터리 장애·명시적 재시도 |
| 삭제한 발신자에 파일 정리 재시도 불가 | 별도 cleanup과 반복 DELETE·중복 이력 방지 | 삭제한 설정의 증빙 정리 실패/재시도 |
| 처리 중 코드/DNS/대표 기한 종료에도 확정 가능 | 감사 뒤 원래 확인 기한·인증 기한 재검사 | 실제 만료와 전체 SQL 롤백 |
| 정규화 중 사라지는 쿼리 키·마지막 페이지 공백 | 제한된 Proxy와 중복 쿼리 검사·정렬/페이지 보정 | handler 시험·최종 production HTTP 70개 |
| 마지막 Job 대기 중 확인 코드 만료 | 현재 주소·환경·세대·임대와 게시 직전 기한 검사 | 실제 Job 잠금 대기·로컬 파일 부재 |

생성 cache의 finalCheck, 증빙 업로드/연결의 기한과 다운로드의 기존 현재 권한 검사, DNS 외부 조회 뒤 현재 version/확인값 재검사를 대조했다. 물리 정리는 확정된 원문 무효화 기록만 대상으로 한다. 사본 정리 실패를 완료로 표시하지 않는다.

현재 화면·실제 외부 공급자·운영 복구 사본은 검증되지 않았다. 전체 회귀 844개·실제 HTTP 70개가 통과했으며 최종 입력/결과 해시를 대조했다.
