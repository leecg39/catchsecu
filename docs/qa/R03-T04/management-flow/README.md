# 회사·서비스 독립 DB·HTTP 수용 체크포인트

2026-10-10. 로컬 개발 DB와 전용 합성 계정만 사용한다. 전체 R03 완료가 아니다.

`scripts/qa-rea-management.ts`는 브라우저가 만든 결과를 새 로그인 세션·HTTP API·별도 Prisma 조회로 대조한다. 허용된 데이터 생성/수정은 브라우저에서 수행했으며, 이 스크립트의 쓰기 요청은 회사 컨텍스트 전환과 반드시 거부되어야 하는 사례다.

- `verified.json`:23개 HTTP 검사 통과. 익명/권한 없는 멤버/다른 회사, 오래된 버전, 잘못된 입력, 동일 서비스명, 의존성 보관 거부, 검색·페이지 보정, 회사 폐쇄 요청 검증, 삭제된 파일 접근 거부.
- 회사 version8·active·폐쇄 요청 없음·첨부2개 삭제, 서비스 version5·active. 기본 서비스·소유자·정책·trial 구독 자동 생성도 독립 DB 확인.
- 회사 감사9건·서비스 감사5건 순서 일치. 실패 요청은 업무 개정·감사를 늘리지 않는다. 실제 UI 다운로드1426바이트가 원본 PDF와 같다.
- `verified-after-restart.json`: 새 프로세스에서도23개 HTTP 검사와 DB 대조가 통과했다. 재시작 전후 업무 상태·감사 지문 `5655a9f35b62c500939ea1642a93e5b3d6216f679d64d173ac7436389333e694`가 일치한다. 서버 준비 전 첫 연결 실패 로그도 보존했으며 준비 완료 후 재실행 결과다.
