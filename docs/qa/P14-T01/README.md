# P14-T01 로컬 데이터 이전·가짜 상태 제거

## 개요

기존 브라우저 localStorage 기반 가짜 상태 및 프로토타입 임시 데이터를 완전히 제거하고, 모든 도메인 저장을 영속 PostgreSQL 데이터베이스로 전환한다.

## 구현 내용

1. **상태 이전 및 정화**:
   - 프론트엔드 내 localStorage 도메인 의존성 제거
   - 모든 폼 작성, 응답 접수, 회사 정보, 프로필 수정을 백엔드 REST API(`src/app/api/v1/...`)와 영속 DB로 일원화
   - 임의 토큰 발급 및 하드코딩된 식별자 배제

## 검증 내역

- 테스트 스위트: `scripts/verify-plan.py`, `tests/server/form-module-flow.test.ts`
- 주요 검증 항목:
  - 브라우저 스토리지 초기화 후에도 DB 영속 데이터 정상 로딩
  - 재로그인 및 다른 브라우저 세션에서의 데이터 일관성 확인
