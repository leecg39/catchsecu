# R12-T03 외부 공유 화면 검증

2026-10-14. `http://localhost:3121`(production 빌드)에서 관리자 공유 관리와 열람자 인증 경로를 실제 브라우저로 확인했다.

## 관리자 화면 — `/form/manage/applicant/{formId}`

- **외부 열람자 관리** 패널: "게시 버전과 항목을 지정해 응답을 공유합니다. 이후 추가한 버전·항목은 자동으로 공유되지 않습니다" 안내 — 범위 고정 명시.
- 외부 열람자 초대 버튼, 상태 필터(열람 가능/만료/회수), 이메일 검색, 목록 새로고침.
- 실제 R12 행 2건: `r12-viewer-b…` 열람 가능(수정·초대 재발송·회수·열람 로그), `r12-viewer-a…` 회수 상태 표시.

## 열람자 화면 — `/shared-privacy/*`

- `/shared-privacy/verify`: 캐치폼 코드·열람자 인증코드·열람자 이메일 입력과 "필수 · 개인정보 수집이용 동의" 체크를 구분 렌더, 이메일 인증 버튼.
- `/shared-privacy/view`: 세션 없으면 "외부 열람자 이메일 인증이 필요합니다"+"다시 인증하기" 게이트.

## 누적 브라우저 증거

- 초대→잘못된 코드→인증 성공→공유 파일→범위 변경 거부→새 범위→회수→열람 로그·390px: [docs/qa/sharing/](../sharing/) (01~12.png + browser-*.json).

## 판정

로컬 화면 검증 완료. 외부 제공사 차원 없음.
