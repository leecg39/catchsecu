# R05-T03 MY 화면 연결 완료

2026-10-11 현재 빌드, PostgreSQL 개발 DB와 Ego Lite 작업공간2/p5에서 확인했다. 기존 프로필·검토·탈퇴 구현에 빠져 있던 목록 주소 복원을 보완했다.

- 내 활동 로그와 검토 목록의 검색·날짜·상태·범위·페이지·행 수를 URL에 저장한다. 명시적인 `20행`과 `20페이지`를 기본값으로 오인해 지우지 않는다. 날짜·UUID·페이지 입력을 검증하고 마지막 페이지 초과는 서버 반환값으로 주소도 보정한다.
- 검토 상세 선택도 URL과 동기화한다. 닫은 뒤 새로고침하면 다시 열리지 않는다. 뒤로 가기의 미저장 메시지 경고에서 취소하면 입력과 포커스를 유지한다.
- 실제 브라우저에서 검색 후 뒤로 가기의 입력란 불일치를 발견하여 수정했다. 최종 검사에서는 주소·검색 입력·표가 함께 복원됐다.

프로필/기기 조회 실패 재시도, 프로필 저장·재로그인·409 입력 유지, 마지막 SSO 수단 해제 차단, 검토 요청/답변/처리/원문 파기와 충돌, 소유자 탈퇴 금지 및 비소유자 실제 폐쇄 흐름은 [앞선 실제 브라우저 증거](../profile-flow/README.md)를 재사용한다. 그 화면의 이번 변경은 없으며 현 소스 해시를 품질 기록에 남겼다. 데이터 표는 최신순 고정으로 DB/API와 대조했으며 임의 정렬 기능을 검증했다고 주장하지 않는다. 날짜 검증의 입력은 네이티브 DOM setter와 input/change 이벤트를 사용했다.

합성 사용자와 원본 감사 이벤트는 시험 준비로 DB에 직접 넣었고, 새 검토 11건은 실제 생성 API를 거쳤다. 원본 운영 사이트에는 쓰지 않았다. 앞선 종결 검토 2건을 이번 입력 시험에 사용하지 않았다. 실제 외부 SMTP·IdP 수신과 원본 내부 구현의 완전한 동일성은 이 UI 완료에 포함하지 않으며 R05-T04에서 별도 상태로 관리한다.
