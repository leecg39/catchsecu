# CSV 수집 근거와 문서 기초 자료 구현

P05-T01을 먼저 구현해 P07-T01 CSV import와 문서 작성이 같은 수집 목적·제공/수탁자 자료를 사용하도록 한다. 원본 두 수집 목적 화면은 라이선스로 가려져 있어 아래는 독립 구현 계약이다.

1. 회사·서비스에 속한 ProcessingPurpose, Recipient와 연결 관계를 만든다. 목적·항목 분류·수집 근거·보유 기간 유형, 국내/국외 제공·수탁·원자료 제공자 정보를 검증한다.
2. 생성·조회·검색·페이지 이동·수정·보관·복원을 API와 두 기존 경로에 연결한다. 현재 회사/역할/서비스 권한을 DB 트랜잭션에서 확인한다. 수정·보관·복원에는 version을 요구한다.
3. 모든 변경의 불변 개정본을 보존한다. 수집 목적 저장 시 연결된 제공자의 당시 설정도 개정본에 남긴다. 보관된 제공자는 새 목적에 연결하지 못하며, 활성 목적에 사용 중인 제공자 보관은 거부한다.
4. Unicode CLDR의 유효 국가·지역 코드를 고정 자료로 사용한다. 항목 중복·빈값·잘못된 기간·국외이전 필수 정보·회사/서비스 교차 연결은 API와 DB에서 검사한다.
5. 실제 PostgreSQL에서 C/R/U/보관/복원, 개정본 불변, 권한 회수, stale version, 중복·경합·교차 참조를 검증한다. Ego에서 실제 생성·수정·새로고침·보관·복원을 조작하고 독립 DB와 대조한다.
6. 후속 CSV 흐름은 파일 검사 → 컬럼 매핑 → 수집 근거/제공자 선택 → 검증 preview → 명시적 반영 → 실패행 다운로드로 구현한다. CSV 원본/실패행 보유와 가져온 응답의 파기를 함께 연결한다. 이 단계가 실제로 구현·검증되기 전까지 CSV 완료로 표시하지 않는다.

문서 공개·PDF·CSV 반영과 보유 정책 집행은 이 기초 자료 CRUD의 완료와 구분한다. 수집 근거 입력을 법적 적합성 판정이나 실제 정보주체의 동의 증명으로 표시하지 않는다.
