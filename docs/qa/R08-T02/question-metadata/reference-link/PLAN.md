# F3 참고 자료 — LINK 구현 계획

추가 설명 검증 기록은 별도로 보존한다. 이번 단위는 질문 참고 자료 LINK의 저장·조회·수정·순서 변경·삭제·공개 표시다. FILE은 작성자 자산의 소유권·검사·참조 수명주기가 필요한 후속 단위다.

## 근거와 계약

[source-review.json](source-review.json)의 정확한 원본 발췌를 사용한다. 원본은 링크와 파일을 같은 `materialList` 배열에 합쳐 3개로 제한한다. LINK wire는 `{materialType:"LINK",orderNumber:0,fileKey:null,linkLabel,linkUrl}`이며 순서는 0부터 시작한다. URL은 trim 후 http/https, 최대 512 UTF-16 단위다. 표시명은 trim 후 최대 100단위이며 빈 이름은 URL 앞부분으로 대체한다. 공개 화면은 추가 설명 앞의 새 탭 링크이며 `noopener noreferrer`를 사용한다. 참고 자료 끄기는 확인 후 배열 자체를 지운다. 원본 서버 정규화·권한·DB 검사는 미관측이다.

1. **모델/계약**: `Question.materialList` nullable JSON을 추가한다. 기존 행은 null, DTO는 필드를 생략해 기존 지문을 보존한다. LINK 배열 0~3개와 strict 항목을 지원하고 FILE·다른 키·다른 종류는 명시적으로 거절한다. 순서는 0 기반 연속 `orderNumber`로 저장한다. `[]`는 명시적 삭제, 생략은 같은 현재 logical ID의 값 보존이다. URL·표시명의 잘못된 Unicode/NUL을 거절하고 UTF-16 길이를 직접 검사한다.
2. **독립 구현 보강**: 서버에서 URL을 가져오거나 미리보기를 만들지 않는다. `http(s)://` 절대 URL, 사용자정보 없는 URL, 제어문자·역슬래시 없는 URL을 허용한다. 이는 원본보다 명시적인 독립 계약이다. URL은 trim 후 원문을 보존한다. 표시명 fallback은 100 UTF-16 이내이며 surrogate를 중간에서 자르지 않는다. DB는 JSON 형태·개수·종류·필수 필드·길이·순서·프로토콜을 검사하고 기존 게시 질문 불변 트리거를 유지한다.
3. **업무 연결**: 생성·초안 수정·implicit draft·revise·copy·템플릿 생성/수정/사용·공개 DTO·승인 snapshot/hash에 연결한다. 기존 질문·보기의 물리 ID를 유지한다. 수정 시 승인 무효화·version·감사 트랜잭션을 따른다. 기존 응답 정정은 원래 게시 version의 링크를 보여준다. 설명·답변·영수증·PDF·CSV 계약의 현재 의미를 유지한다.
4. **화면**: 질문별 참고 자료 사용, 추가/수정 모달(URL 필수·표시명 선택), 3개 상한, 목록 순서 변경, 개별 삭제 및 전체 끄기 확인을 제공한다. 취소는 기존 값을 바꾸지 않는다. 모달 입력에 이탈 보호를 연결한다. 모달 확인 시 한 번에 상위 초안에 반영해 URL 입력 도중 자동저장 실패를 피한다. 공개·요약·미리보기·승인·응답 조회/정정은 공통 평문 링크 컴포넌트로 표시하고 분기 숨김을 따른다. 첫 단계에 미구현 FILE 버튼을 두지 않는다.
5. **시험**: 구현 전 누락 RED, 길이 512/513·100/101·astral·금지 URL·FILE/4개·잘못된 order/JSON·기존 null/DTO hash를 검사한다. 추가·수정·삭제·생략 후 복원 방지, 복사·템플릿·개정, 승인·409·권한 회수·감사 롤백, 직접 DB 제약·게시 불변, 구 응답·영수증/PDF 유지를 실제 DB로 검증한다. DB 시험과 migration은 주 에이전트만 직렬 실행한다.
6. **이관**: 기존 8개 테이블 공통 컬럼 지문과 새 컬럼 null, dev/test/빈 스키마 migration119·구조 검사, 이전 15개 고정 fixture 지문을 확인한다. 새 null 필드만 검증 후 과거 해시에서 제외하며 기존 baseline을 덮어쓰지 않는다.
7. **실제 수용**: 별도 QA 회사의 Ego에서 추가·편집·취소·순서·3개 상한·삭제 확인 취소/확정·전체 끄기·새로고침을 확인한다. 공개 분기·링크 속성·새 탭 동작, 제출·정정·새 게시본·구 링크 유지도 검사한다. 390/768/1440px·키보드·실제 DB/API·production 재시작·관련 회귀·타입·린트·빌드·OpenAPI와 파일 지문을 기록한다. 이미지 캡처가 불가능하면 시각 검증 미완료를 명시한다.
