# 참여자 인증 외부 의존성

## 카카오·네이버 소셜 로그인

실제 공급자 수용에는 각 개발자 콘솔에서 만든 애플리케이션, client ID/secret, 승인된 callback URL과 서비스 도메인, 테스트 계정이 필요하다. 현재 내부 계약·DB·설정 UI와 공급자 미설정 시 게시 거부까지 구현했다. 실제 OAuth 성공·거부·취소·계정 회수 흐름은 검증 전이며 완료로 집계하지 않는다.

## 이메일 전달

이메일 OTP 생성·만료·시도 제한·검증·세션 발급은 로컬 암호화 outbox로 확인했다. 운영 SMTP 도메인, DNS 승인, 테스트 수신함과 반송 webhook이 준비되면 실제 수신·반송 흐름을 추가 검증한다.
