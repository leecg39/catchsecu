# F3/F5 폼 언어·국제 연락처 실행 계획

2026-10-10. 승인된107개 작업의 R08-T01/T02와 F3/F5를 구체화한다. 원본 [분석](source-review.json)의 관측과 독립 구현 정책을 구분한다. 국제 전화는 별도 질문 유형이 아니라 CONTACT와 폼 언어의 조합이다.

1. **게시 버전의 언어 모델**: FormVersion에 nullable `formLanguage`를 추가하고 원본16개 코드만 DB/API에서 허용한다. 이전 행은 null로 유지하고 읽기에서는 필드를 생략해 기존 승인 지문·템플릿 JSON·게시 응답을 보존한다. 새 편집기는 한국어를 명시한다. 복제·개정·템플릿 사용·공개 읽기·정정은 해당 버전의 언어를 사용한다. 언어 변경은 새 초안만 바꾸며 기존 게시본에는 적용하지 않는다. 한국어 이외의 본인인증/서명 활성화는 원본 제한대로 거절한다.
2. **서버 연락처 계약**: 한국어/기존 null은 기존 국내 계약 유지. 비한국어는 원본의 `+국가번호 공백 숫자6~15자리` 문자열을 저장하고 허용 전화코드는 기존181국가/179코드 목록에서 확인한다. 직접 숫자 주입·없는 코드·객체·6미만/15초과·숨긴 응답·필수 누락을 거절한다. 원본 서버 검증은 미관측이므로 이 서버 강제 규칙은 독립 구현이다. 국제 답변의 전체 E.164 길이를 일괄15자로 제한하지 않는다.
3. **편집 화면**: 원본의 언어 선택·확인 흐름과16개 언어를 연결한다. 언어 전환 시 주소/해외 주소 타입만 전환하고 질문 ID는 유지한다. 질문 제목/본문/보기의 자동 번역을 주장하지 않는다. 게시본 수정·충돌·저장 실패 시 기존 초안 보호를 유지한다.
4. **공개 입력·정정**: 국가 ISO 선택/국가명 번역/번호 입력을 연결한다. 기본 국가 없음, 국가 변경 시 번호 보존, 숫자 필터/입력상한30·실제검증6~15, 선택값도 부분 입력은 거절한다. 저장된 문자열은 국가코드가 유일한 경우만 ISO 복원한다. +1/+7은 두 국가를 함께 표시하는 기존 전화코드 선택값으로 유지해 한 국가를 추정하지 않는다. 선택 질문의 명시적 전체 비우기는 독립 사용성 개선이다. 처리 중 잠금·취소 복원·정정·이력·CSV와 국가별 표시를 검사한다.
5. **언어 표시 범위 점검**: 원본 시스템 문구의16개 언어 자료를 조사해 공개 화면에 필요한 문구를 연결한다. 사용자 작성 내용은 그대로 보존한다. 완성하지 않은 번역/본인확인/동의서 조합을 전체 언어 기능 완료로 표시하지 않는다. 아랍어의 방향성과390/768/1440px 레이아웃을 확인한다.
6. **실패→수정 시험**: 새 통합시험을 먼저 실행해 누락을 확인한다. 언어 CREATE/READ/UPDATE·복제/개정/템플릿·버전지문, 구 승인/응답 불변, 잘못된 언어/직접DB UPDATE 차단, 국제 제출/정정 암호화·공유코드·조건부 숨김·CSV를 실제 DB에서 검증한다. 마케팅 발송 계약의 전체번호 길이는 별도이며 부적합 동의의 원자적 거절과 미동의 제출을 구분한다.
7. **데이터 보존·최종 수용**: migration 전후 기존8테이블 공통 컬럼 전체 해시, 신규 필드 null, dev/test/빈스키마117개 설치·구조 차이0, 기존13개 고정 fixture 보존을 확인한다. API 준비/거절과 Ego 실제 언어 변경→공개 제출→정정/취소/CSV→프로세스 재시작을 실행한다. 타입·린트·빌드·필요 회귀와 증거를 남긴다. 전체 F3/F5/R08/107개 작업 상태는 별도 완료 기준을 유지한다.

DB를 변경하는 마이그레이션·시험은 주 에이전트가 직렬 실행한다. 원본 분석 에이전트와 백엔드 구현 에이전트는 담당 파일만 수정하며, 다른 작업자의 변경을 되돌리지 않는다.
