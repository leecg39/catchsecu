# P13-T03 내비·모달·캐시 라이브 게이트 (2026-10-04)

dev 앱 :3100에서 owner·viewer 세션으로 내비게이션·권한 연동·캐시 일관성을 실측했다.

| 검증 | 결과 |
|---|---|
| 최상위 메뉴 역할 공통 | owner·viewer 동일 그룹 렌더 — 권한 구분은 액션/API 계층에서 수행 |
| viewer 보안 화면 접근 | `/security/ip` 셸 200이나 "최상위 관리자만 변경" 안내 + 데이터 API 403 — 셸과 데이터 권한 분리 정상 |
| MY 메뉴 | 클릭 시 "마이페이지"·"로그아웃" 실제 액션 노출 |
| 대시보드 실데이터 | 라이선스(trialing·2/10·종료일)·보유 3건·순위·마케팅 0이 API/SQL과 일치 |
| 캐시 일관성 | IP 정책 끄기 직후 `/security/compliance`가 즉시 "꺼져 있습니다" 반영 — stale 캐시 없음 |
| visible action 연결 | 모든 링크가 실제 경로(공지·문의·알림·라이선스·폼/문서 관리·서비스 상세)로 이동 — `href="#"` 더미 없음 |
| loading 상태 | `/loading`·`/service/none`이 context 조회 스피너 상태 표시 |
| forbidden 상태 | viewer 데이터 API 403(P11-T02 게이트와 동일 증거) |
| validation 상태 | 공지·발신자·IP 규칙 폼의 서버 422가 화면 오류로 표시(P13-T01/P11-T02 게이트와 동일) |

## 남은 조건

- "모든" visible action 전수 스윕·서비스 전환 드롭다운 조작·conflict/retry 전 상태는 P13-T04 전체 화면 게이트(181경로 직접URL·새로고침·뒤로·모바일)에 속한다.
- Table/Form 공통 상태의 전수 조합은 미검증.
