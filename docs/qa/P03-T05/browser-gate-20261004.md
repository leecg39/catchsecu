# P03-T05 관리 페이지 CRUD 게이트 — 브라우저 증거 (2026-10-04)

live Chrome(DevTools MCP) + dev 서버(3100) + `catchsecu_dev`로 회사 A/B 양방향 E2E와 목록 CRUD 게이트를 확인했다. 화면 스냅샷과 DB 행을 직접 대조.

## 환경·계정
- 회사 A: `admin-20261003@catchsecu.local.test` (캐치시큐 테스트 회사 A, 기본/제한 서비스)
- 회사 B: `owner-b@catchsecu.local.test` (캐치시큐 테스트 회사 B, 회사 B 서비스)

## 1) 회사 A — /form/manage (폼·업로드 목록)
- 렌더: 검색, 상세 검색, 정렬 기준(생성일/캐치폼명)×순서(내림/오름차순), 즐겨찾기 필터, 페이지당 행 수(10/20/50/100), 이전/다음 페이지, 총 건수
- 행 액션 9종: 미리보기/편집/템플릿 등록/복사/공유/일시 중지/보관/완전 삭제/즐겨찾기
- 표시 3건: 라우트 fixture 폼·브라우저 재사용 템플릿·브라우저 CRUD 검증 폼 — 공개상태·서비스명·생성자("owner A")·현재 게시 응답·생성일·보유 기간 모두 실데이터
- **DB 대조**: 기본 서비스 Form 7건 중 `published` 3건 = UI 3건 (archived 4건 "P01 계약 A/B" 미노출 — 목록이 게시 폼만 표시)
- **검색**: "라우트" 입력 → 1건(라우트 fixture 폼)만 필터, 총 1개로 갱신
- 배너 "캐치시큐 테스트 회사 A"·서비스 컨텍스트 "기본 서비스" — 하드코딩 회사/담당자 표시 없음

## 2) 회사 A — /form/manage/applicant/[formId] (응답 목록)
- 브라우저 재사용 템플릿 응답 페이지: 제출 기간(시작/종료일) 필터, 응답 상태 6종(전체/제출 완료/정정/철회/파기 요청/파기 처리 중/파기), 응답 ID 검색, 검색/초기화
- 동기 CSV 내보내기(최대 5,000건·20MB, 종료일 포함 고지) + 비동기 CSV(최대 100,000건·20MB, 결과 24시간 보관 고지, 작업 목록 페이지네이션)
- 응답 1건: `450836a3-e096-496e-821d-a48dc50dc1eb`, 응답 내용(수정명/참가자/교육 과정), 제출일 2026-10-02 19:56, 보유 기한 2026-12-01, 상태 "제출 완료"
- **DB 대조**: Submission 1건 — id·status(submitted)·submittedAt 일치
- 외부 열람자 관리 섹션: 초대 버튼·공유 상태 필터(전체/열람 가능/만료/회수)·이메일 검색·빈 상태("초대한 외부 열람자가 없습니다")

## 3) 회사 A→B 침범 차단 (회사 A 세션)
- `GET /api/v1/services/{회사B 서비스}/subprocessors` → **404**

## 4) 회사 B — 동일 경로 E2E
- 로그인(owner-b) → 배너 "캐치시큐 테스트 회사 B", 서비스 컨텍스트 "회사 B 서비스"
- /form/manage: 동일 검색/정렬/페이지 UI, "데이터가 없습니다" 총 0개 — 회사 A의 3개 폼 비노출 (**DB: 회사 B Form 0건 일치**)
- **회사 B→A 침범 차단**: `GET /api/v1/forms/{A폼}` → 404, `…/submissions` → 404, `GET /api/v1/services/{A 기본서비스}/subprocessors` → 404 — 양방향 IDOR 없음

## 5) 서비스 2개 스코프
- 회사 A 서비스 선택자: 기본 서비스/제한 서비스 — P03-T04 게이트에서 제한 서비스 전환 시 수신자 0명(스코프 분리) 확인
- 회사 B: 단일 서비스 컨텍스트로 B 데이터만

## 판정
- 수용 조건 "회사A/B·서비스2개 E2E; 브라우저와 DB 조회 일치"를 양방향 세션으로 충족.
- 검색·정렬·페이지네이션·빈/오류 상태·행 액션이 live 데이터로 동작.
- 경합·권한 재검사 심층은 서버 스위트(company-management, member-management-gate, tenant-boundary)와 P03-T04 revalidation(recipient-send-conflict, subprocessor-authority-*) 증거가 커버.
- UI 캡처는 MCP workspace 제약으로 파일 저장 불가 — 본 문서가 화면 스냅샷(접근성 트리) 기반 기록.
