# R06 보안 서버 검증

보안정책 조회에서 초기 인증 후 권한/세션/정책이 변경된 경우 오래된 Context만 신뢰하는 문제를 재현하고 수정했다. 조회 트랜잭션 안에서 회사·사용자·소속·세션·IP·MFA·비밀번호 기한을 다시 검사하며, 응답의 수정 가능 여부도 현재 역할을 따른다.

- [수정 전 재현](current-authority-before.json): 9개 중 정상 조회 1개 통과, 경계 8개 실패. 관리자 강등, 조회자 변경, 소속 회수, 세션 삭제/만료, 이메일 확인 해제, MFA 강제, IP 변경을 포함한다.
- [수정 후 및 회귀](authority-regression.json): 6파일 104개 모두 통과. 위 9개와 정책·IP·MFA·비밀번호·게시 승인 시험이다.
- [파일/내보내기/worker](files-workers.json): 별도 4파일 77개 모두 통과. 현재 권한/기한, 파일 바이트 접근, 변경된 MFA 정책의 worker 적용을 포함한다. 이 실행은 마지막 정책 조회 보완 전에 수행했으며 파일/worker 코드는 그 뒤 변경하지 않았다.
- [초기 95개](baseline.json)는 회귀 104개와 중복되므로 더하지 않는다. 관련 고유 시험은 181개다. 과거 전체 1,834개 결과를 새 전체 회귀로 주장하지 않는다.
- 실제 소켓 기반 [IP HTTP 경계 20개](../../R06-T04/security-flow/ip-boundaries.json), [MFA 실제 만료 8개](../../R06-T04/security-flow/mfa-expiry.json).

기존 계약의 잘못된 CIDR 응답은 422/INVALID_CIDR이다. 계획에 적힌 400을 실제 계약과 시험 결과에 맞춰 422로 바로잡았으며 서버 응답 코드를 임의로 변경하지 않았다.

Enterprise 포함/미포함·라이선스 만료별 보안 관리 권한은 아직 별도 구현/검증이 필요하다. 현재 entitlements는 수량 한도를 검사하며 이 보안 API에는 기능별 gate가 연결되지 않았다. 이 범위를 완료로 집계하지 않는다.

## 기능 권한 후속

위의 미연결 gate는 이후 [기능별 구독 권한 구현·225개 고유 회귀](../security-entitlements/README.md)로 보완했다. 원본 서버의 상품별 매핑과 외부 결제 제공사 수용은 별도로 남아 있다.
