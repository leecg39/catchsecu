# 기능별 보안 관리 권한

회사 정책·IP·회사 MFA의 모든 변경 경로에 실제 DB 구독 검사를 연결했다. 읽기는 현재 역할 권한을 적용하며 기능 상태를 포함한다. 구독 없음도 허용하지 않고, 만료 후에도 기존 IP/MFA/암호/세션 보호를 유지한다. 개인 MFA에는 상품 제한을 추가하지 않는다.

구독 행을 잠가 해지와 변경을 직렬화하고, 커밋·생성 재시도 응답 직전에 유효 기한을 재확인한다. 회사 정책에서 requireMfa를 변경하는 경로도 별도 MFA 기능 권한을 요구한다. 실패한 변경은 데이터·감사 기록을 함께 롤백한다.

- [첫 시험](initial.json): 25개 중 21 통과. 남은 4건은 테스트의 기존 인증 감사 개수 및 마지막 MFA 관리자 DB 제약을 잘못 가정한 것으로, 시험 준비/검증식을 수정했다.
- [관련 회귀](regression.json): 13파일 204개 통과.
- [기능 및 해지 직렬화](final-feature-tests.json): 26개 통과. 204개 결과와 25개가 중복되므로 합계 230개로 집계하지 않는다.
- [교착 최초 확인](worker-lock-before.json), [명시적 재현](worker-deadlock-reproduced.json): 설정 저장과 만료 worker의 회사/구독 잠금 순서가 달라 PostgreSQL deadlock이 발생했다. P2010 및 deadlock=true로 확인했다. worker가 회사부터 SKIP LOCKED로 잠그도록 수정했으며 최종 결과는 후속 보고서에 기록한다.

기존 테스트의 직접 Company 삽입에는 이제 [명시적 시험 구독](../../../../tests/fixtures/security-subscription.ts)을 붙인다. 운영 코드의 권한 검사를 생략하는 시험 전용 분기는 추가하지 않았다.

실제 앱 HTTP 및 Ego 화면/자연 만료/재시작 검증: [증거 폴더](../../R06-T04/security-entitlements). 원본 서버의 정확한 요금제 매핑과 외부 제공사 연결은 미검증이다.

## 최종 결과

[worker·기능·구독·결제 회귀](worker-and-features-final.json) 6파일86개가 모두 통과했다. 기능 시험27개에 교착 재현의 수정 후 성공도 포함된다. 앞선204개와 시험 식별자로 중복을 제거하면16파일225개다. 새 전체 프로젝트 회귀라고 주장하지 않는다.
