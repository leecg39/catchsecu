# 조직 이메일 등록 원자성 후속

범위: VirtualOrgMember 이메일 등록과 SSO JIT/감사/일회성 티켓 소비를 같은 트랜잭션에서 수행해 인증 실패 시 모두 롤백한다. 기존 OIDC/SAML/초대/연결 동작은 보존한다.

재현: 공급자 정지, 기존 이메일 충돌, 로그인 감사 실패, 등록 도중 기한 만료에서 디렉터리 변경/등록 감사 잔존을 확인한다. 정상/동시 등록과 변한 디렉터리 거부도 확인한다.

수정: completeSso의 회사/공급자 잠금·최신 상태 검증 뒤 같은 tx에서 실행하는 내부 준비 콜백을 추가한다. 조직 등록은 tx 안에서 구성원 현재 버전·빈 이메일·티켓 일회성을 다시 확인하고 이메일/감사를 기록한다. completeSso 실패는 등록 쓰기를 롤백한다.

검증: 새 재현→수정 후 org-auth 및 SSO/보안 영향 범위 순차 시험, 타입·린트·빌드, 비밀 검사, 커밋·푸시. 실외부 성공/브라우저 새 실행으로 표시하지 않는다.
