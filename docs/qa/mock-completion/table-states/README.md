# 공통 목록 상태의 모바일 가시성 수정

2026-10-06. 기존 모바일 화면에서 빈 목록 안내가 넓은 표 가운데 배치되어 가로 스크롤 없이는 보이지 않았다. `/mail`의390px 화면에서 문구 좌표491.34~590.66px로 실제 재현했다.

`RemoteTable`의 로딩·오류·빈 목록 상태를 가로 스크롤 표 밖에 표시한다. 데이터 행·헤더·페이지 이동은 유지하고, 로딩/오류 시 과거 행은 계속 숨긴다.

- 상태별 단위시험4개 통과: 정상행, 로딩, 오류, 빈 목록 및 페이지 경계.
- [Ego 실제 검증](report.json): 메일·문자·메일이력3화면 ×1440/768/390의9검사에서 문구가 화면 안에 있고 표 밖에 표시되며 페이지 가로 넘침0.
- 실제 문서 목록의 기존 데이터행 유지, 빈 목록 안내가 잘못 표시되지 않음 확인.
- 모바일 메일 캡처를 직접 검토했다. 캡처는 `.local/table-states/`에 보관한다.
- 변경 파일 린트·타입 검사·production 빌드 통과. 최신 전체 회귀 결과는 상위 `full/report.json`에 기록한다.

기존 SourceIcon과 공통 빈 목록 문구를 재사용한다. 원본 서비스와 전체181경로의 수용 완료를 뜻하지 않는다.
