# 잔여 작업 실행 순서

1. 문자: 잔고 행 잠금 대기 중 원천 보유 기한 만료를 별도 연결과 실제 DB 장벽으로 재현한다. Mock 영수증 없음·capture0·잔액 반환을 요구한다. 같은 경계를 알림톡 대체 문자에도 적용한다.
2. 이메일: 첨부 파일 읽기 장벽에서 원천/캠페인 기한이 지난 경우를 재현한다. 파일 읽기 후 발송 직전 상태를 검증하고 파일/SMTP 호출 부재를 확인한다. SMTP 불확실 재전송 방지 규칙은 유지한다.
3. 역할별 채널 UI와 기본 검사 뒤 미재방문 인증/공개25경로를 기존 Ego56/p1에서 검사한다. 실제 페이지/Mock 계정·초대·SSO state·토큰으로 정상/실패/만료/권한 흐름을 나누고 임의 토큰이나 로그인 이동을 정상 수용으로 집계하지 않는다. 실패·미측정은 명시한다.
4. 최신 스키마101번째 마이그레이션을 포함한 Mock 복구 증거와 최신 전체 회귀를 반영한다. 원래 작업별 게이트 요구와 Mock 대체 증거를 한 행씩 연결해 부족한 증거를 채운다.
5. 원본 대조128제한은 인증된 원본 화면 증거가 생길 때 비교한다. Mock 대체는 외부 공급자 증명에 대한 지시이며 원본 화면 대조를 대신하지 않는다. 전체완료 판정은 남은 원래 조건을 확인한 뒤 한다.

각 단계는 계획→재현→구현→적대적검토→수정→검증→커밋·푸시로 진행한다. 현재 전체목표는 활성 상태다.
