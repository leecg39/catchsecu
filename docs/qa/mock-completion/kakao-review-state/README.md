# 알림톡 목록·채널·심사 동시성 후속 검증

2026-10-06. 외부 확인·승인/반려는 사용자 지시에 따라 로컬 Mock 공급자로 대체했다. 이번 결과를 실제 공급자 승인이나 전체 원본 대조로 확대하지 않는다.

## 수정

- 채널·템플릿 등록 실패 시 입력을 유지한다. 서버에 저장된 뒤 응답만 유실되면 동일 입력과 요청 키로 재시도한다. 동시 클릭은 한 번만 전송하며, 성공한 경우에만 입력을 비운다.
- 회사/서비스별 작성 화면을 분리하고 요청 중 서비스 변경을 잠근다. 관리 권한이 없으면 목록을 요청하지 않는다. 목록 로딩·오류·빈 상태와 재시도를 표시하며 채널 조회 실패 동안 등록을 잠근다. 템플릿 이름 길이는 계약의100자를 적용한다.
- 채널 수정·삭제·템플릿 생성은 같은 채널 행을 잠그고 최신 버전·상태를 검사한다. 활성 템플릿이 있는 채널의 삭제/보관을 차단해 DELETE로 보관 검사를 우회할 수 없게 했다.
- 채널 검색 ID가 달라지면 확인 상태를 해제한다. 보관되지 않은 연결 템플릿도 초안으로 전환하고 버전을 증가시켜 이전 채널 승인·예약 캠페인 고정을 무효화한다. 변경 감사는 상태 변경과 같은 트랜잭션으로 저장한다.
- 심사 콜백 계약에 대상 `version`을 필수로 추가했다. 서명과 대상 버전·대기 상태가 모두 일치해야 반영하며, 이전 신청/중복/동시 결과를 거절한다. 버전 없는 이전 형식은422다. 실제 공급자 어댑터가 추가될 때 공급자의 신청 식별자와 제출 버전 매핑이 필요하다.
- 로컬 채널 확인과 즉시 심사는 현재 권한 검사·상태 변경·감사를 같은 트랜잭션에서 처리한다. 감사 저장 실패는 제출과 결과까지 롤백한다. 목록/생성/조회/채널 변경/삭제도 종료 전 기한을 검사한다.
