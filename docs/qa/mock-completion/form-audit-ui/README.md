# 폼별 감사 로그 구현·검증

2026-10-06. `/form/manage/applicant/log/:formId`가 일반 응답 목록을 표시하던 문제를 수정했다. 전용 폼 감사 API와 같은 범위의 CSV를 추가했다. 응답 목록에서 감사 로그로, 감사 로그에서 응답 목록으로 이동할 수 있다.

## 구현 범위

- 현재 회사의 선택 폼·응답·첨부파일·내보내기 작업과 연결된 원장 기록만 조회한다. 동일 서비스의 다른 폼과 회사 공통 로그는 제외한다.
- 본문 조회 권한 없이 감사 권한을 가진 역할도 전용 API를 사용한다. 현재 회사/계정/세션/정책/서비스 권한을 트랜잭션에서 재검증하며 전문가 배정 서비스 범위를 제한한다.
- 기존 안전 DTO와 마스킹을 재사용한다. 기간·처리자·내용/대상 검색, 페이지, 읽기 전용 상세와 CSV5,000건 상한을 지원한다. 검색값·원문·비밀을 결과에 포함하지 않는다.
- 원천 ID 전체를 앱으로 읽지 않고 DB의 EXISTS로 연결을 확인한다. 파일의 폼 버전 연결은 기존 불변성 규칙을 따른다. 원천 참조가 이미 사라져 연결을 증명할 수 없는 과거 이벤트를 임의로 폼에 귀속하지 않는다.
- 서비스 ID가 포함된 응답 URL은 실제 폼의 서비스와 다르면 응답 목록을 렌더하지 않는다. 모바일 빈 안내는 가로 스크롤 밖에 표시한다.

## 적대적 검토와 수정

감사 역할의 폼 본문 권한 의존, 서비스 URI 불일치, 모바일 빈 상태, 잘못된 중첩 export 경로, 오래된 서비스 권한과 다른 폼 누출을 검토했다. 구현과 시험으로 위 조건을 차단했다. 계약 검토에서 누락된 UUID 경로 인자를 추가하고 회사 전용 API에서 자기활동 필터를 노출하지 않도록 정정했다. 원본 충실도·모든 역할의 브라우저 검증은 현재 증거 범위 밖이다.
