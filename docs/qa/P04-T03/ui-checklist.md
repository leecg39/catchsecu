# P04-T03 실제 화면 검증 — 실행 대기

기존 Ego 창의 제어 재개 응답 후 합성 시험 회사에서 desktop/390px를 조작한다. API 시험은 아래 화면 검증을 대신하지 않는다.

| 화면 | 조작·확인 |
|---|---|
| 설정·승인 패널 | 승인 전 게시 차단, 증빙 필수 오류, 검토본 펼치기, 반려·재요청·승인·게시 후 이력 |
| 승인 목록 | 회사/서비스·제목·상태 검색, 마지막 페이지 보정, 폼 설정으로 이동 |
| 고정 URL 목록 | 이름/상태 검색, 서버 페이지 표시, 생성·수정·사용 종료 |
| 고정 URL 편집 | 현재 게시 폼 선택, 다른 폼 연결, 없는/권한 없는/만료한 대상 오류, 동시 변경 409 |
| 공유·공개 응답 | 새 게시 후 같은 주소 연결, 구버전 응답 유지, 중단·재개·실제 만료·응답 한도 |
| 권한 회수 | 현재 권한에 따른 버튼·메시지, 이전 요청 키 재시도의 토큰/검토본 차단 |
| 390px | 목록·모달·승인 검토본·오류·페이지 버튼의 읽기/입력/동작과 가로 넘침 |

원본 정상 승인·고정 URL 화면을 다시 관찰하고 경로/상태별 차이를 기록한다. 각 사례에는 캡처, 실제 API formId/version, 독립 DB 대조를 남긴다. 선행 P04-T02/P11-T01의 전체 게이트까지 갖춰져야 정식 완료다.
