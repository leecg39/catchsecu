## 이번 구현

- `GET /api/v1/analytics/dashboard`: 현재 회사와 서비스 권한을 DB에서 다시 확인하고 활성 서비스만 조회한다. 요청된 서비스가 범위 밖이면 404를 반환한다. 한 `REPEATABLE READ` 트랜잭션에서 폼·동의서·처리방침·현재 보유 응답·기간 내 접수 후 현재 보유 응답·파기 증명서를 집계하고 조회 감사 이벤트를 기록한다.
- `from` 포함·`to` 미포함, 최대 366일. 기본 기간은 한국 시간의 월 첫날 자정부터 시작한다. 브라우저의 종료 날짜는 다음 날 0시로 보내고 현재보다 뒤면 집계 시각으로 제한한다. 보유 기한 경과, 파기 중·파기 완료 응답을 보유 수치에서 제외한다. 보존 조치 중인 응답은 포함한다.
- `/dashboard`와 `/dashboard/:serviceId`의 고정 라이선스 날짜·건수와 예시 순위를 실제 집계, 현재 라이선스, 마케팅 동의 요약으로 교체했다. 기간 필터·새로고침·서비스 상세 이동을 연결했다.
- `/privacy-detail`과 서비스 상세 화면의 예시 회사·수치를 제거하고 실제 응답·파기 현황과 검색·기간 필터를 연결했다. 질문에 민감정보 등 분류가 없어서 유형별 수치는 표시하지 않는다.
- `/marketing-detail/:serviceId`에서 서비스 ID를 서버 요약 API에 전달하고, 서버가 현재 마케팅 권한과 서비스 grant를 `AND`로 확인한다. 권한 밖 서비스는 404다.
- 마케팅 요약은 현재 동의·철회·삭제·발송 가능 건수와 정보주체 철회/이메일 반송·신고·수신거부로 차단된 동의 건수를 한 `REPEATABLE READ` 조회로 계산한다. 같은 화면의 기간 필터는 불변 동의 변경 이벤트의 동의·철회·삭제 기록을 `from` 포함·`to` 미포함으로 집계한다. 요약 조회도 감사한다. 서비스 목록을 1,000개에서 조용히 자르던 제한을 없앴다.
- 집계 기준 시각을 DB의 첫 문장 시각으로 가져와 트랜잭션 스냅샷과 맞췄다. 대시보드에서 선택한 기간을 마케팅 요약에도 전달한다.
- `/compliance`의 근거 없는 `20/100` 점수, `1원` 과태료, 데모 Excel 보고서를 제거했다. 실제 자료 건수와 미판정 상태를 표시한다.
- OpenAPI에 집계 API와 마케팅 요약의 서비스·기간 필터를 반영했다.

## 검증

- `tests/server/analytics.test.ts`: 실제 분리된 PostgreSQL 시험 DB에서 두 회사·서비스 권한·보유 기한·보존 조치·문서 수·정렬·기간 경계·한국 시간 월 첫날 자정·재집계·감사 이벤트를 확인한다.
- `tests/server/marketing.test.ts`: 서비스 ID 필터, 같은 회사의 권한 밖 서비스와 타 회사 서비스의 404, 잘못된 UUID의 422, 동의·철회 이벤트 집계와 종료 시각 경계·조회 감사를 확인한다.
- `tests/server/campaigns.test.ts`: 실제 로컬 메일의 수신거부 전후에 마케팅 요약의 차단 건수 증가와 발송 가능 건수 감소를 확인한다. DB가 철회되지 않은 응답을 근거로 한 임의 차단 행을 거부하므로 실제 수신거부 흐름으로 시험했다.
- 관련 PostgreSQL 시험 3개 파일·82건 통과, TypeScript 검사 통과, 변경 코드 ESLint 오류 0(기존 `<img>` 경고 4건). production build도 통과했다.
- 한국 시간 기본 월 경계 수정 후 analytics·marketing 시험 2개 파일·28건을 다시 통과했다. 프로젝트가 허용하는 Node 24.19.0에서도 같은 28건, production build, 실제 HTTP·headless Chromium 실행을 다시 통과했다.
- [실제 HTTP 기록](http.txt): 로컬 production 서버에서 7개 관련 경로의 HTML 200을 확인했다. 회사 A의 활성 서비스 2개와 현재 보유 응답 2건, 마케팅 기간 동의 이벤트와 현재 차단 건수를 API와 독립 DB 조회로 대조했다. viewer는 허용된 서비스 1개만 보며, 권한 밖·타 회사 서비스 404, 마케팅 허용 서비스 200·권한 밖 404를 확인했다. 재현 명령은 `node --env-file=.env.local node_modules/tsx/dist/cli.mjs scripts/qa-analytics.ts`다.
