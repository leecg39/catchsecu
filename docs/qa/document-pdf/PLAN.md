# 게시 버전 PDF 구현 계획

P05-T04의 서버 문서 내보내기를 먼저 실행한다. 폼의 문서 선택·동의 영수증 연결은 다음 단계에 이어서 구현한다.

1. DocumentPdf를 문서 게시 버전에 복합 FK로 연결한다. PDF 바이트·SHA-256·본문 해시·렌더러 버전·글꼴 해시를 한 번 저장하고 변경·삭제를 DB에서 막는다.
2. PDFKit과 고정한 한국어 글꼴로 서버에서 페이지 나눔·게시 버전·본문 해시·페이지 번호를 렌더링한다. 네트워크 글꼴/이미지·사용자 HTML은 읽지 않는다. 동일 버전은 같은 저장 파일을 반환한다.
3. 내부 다운로드는 현재 회사·서비스·document.read 권한을, 공개 다운로드는 활성 회사/서비스/문서/링크·만료를 검사한다. 다운로드에도 no-store·nosniff·attachment 헤더와 요청 제한을 적용한다.
4. 문서 버전 목록과 공개 화면에 다운로드를 연결한다. 오류 응답은 파일로 저장하지 않고 화면에 표시한다.
5. PostgreSQL 테스트로 권한/타회사/타서비스/회수/만료, 이전 버전 고정, 동시 생성 1개, DB 변경 방지, 요청 검증과 다운로드 파일 해시를 검사한다.
6. pdftotext·렌더 이미지와 Ego의 실제 다운로드로 한글·여러 페이지·본문·버전/해시·재시작 후 바이트 일치를 확인한다. 타입·린트·빌드와 전체 회귀 테스트를 실행한다.

자료: [PDFKit 글꼴·텍스트](https://pdfkit.org/docs/text.html), [PDFKit 서버 출력](https://pdfkit.org/docs/getting_started.html), [Noto CJK 공식 글꼴](https://github.com/notofonts/noto-cjk).
