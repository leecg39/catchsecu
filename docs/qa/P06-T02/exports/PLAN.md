# P06-T02 비동기 응답 내보내기 구현 계획

2026-10-04 시작 시점의 계획이다. 당시 즉시 CSV는 5,000건·1,000열·20MB 상한이며 `ExportJob` 모델·API·worker·화면은 없었다. 이후 구현과 실행 증거는 [검증 기록](README.md)에 따로 남긴다. 원본 형식 대조와 실제 브라우저는 별도 게이트다.

## 구현 순서

1. **계약·모델**: 회사/서비스/폼·요청자·암호화된 필터, 상태·version·진행 건수·상한·유효 기한·암호화 결과·해시·실패 코드를 가진 ExportJob과 원천 응답 참조를 정의한다. 생성은 멱등하고 같은 키의 다른 입력을 거부한다. 상태는 대기→처리→준비/실패와 취소/만료를 구분한다. 실행 제한·결과 보유 기한은 환경 설정과 검증 가능한 서버 상수로 정한다. 검색어와 응답 원문을 일반 DB 열/로그/감사에 저장하지 않는다.
2. **API**: `POST /api/v1/exports`와 `GET /api/v1/exports`, `GET /api/v1/exports/{id}`, `GET /api/v1/exports/{id}/download`, 취소/결과 폐기를 구현한다. 기존 응답 필터 계약과 현재 권한 검사를 재사용한다. 회사/서비스/폼 경계와 요청자 범위를 검사하고 경로 ID만으로 결과를 열 수 없게 한다. 범위 밖 ID는 404, 만료/파기한 결과는 410, 처리 중 다운로드는 명확한 대기 오류다.
3. **worker**: 별도 claim·lease·재시작/재시도·취소를 기존 작업 처리 규칙에 연결한다. 100건 단위로 읽으며 아홉 유형/행렬/분기·버전별 열·CSV 수식 방어·현재 보유 상태를 기존 즉시 CSV와 일치시킨다. 처리/열/바이트 상한을 넘으면 부분 결과와 원문을 제거한다. 요청자의 현재 계정/배정/역할·서비스 권한을 실행 전후 검사한다. 오래된 worker가 새 lease의 결과를 덮어쓰지 못하게 한다.
4. **원문 회수**: 결과의 응답 참조를 사용해 정정·보유 기간 변경·파기·권한 회수 이후 이전 원문을 다운로드할 수 없게 한다. 다운로드 transaction에서 현재 원천 상태와 권한을 재검사하고 변경된 결과는 폐기하거나 새 요청을 요구한다. 파기 transaction에서는 연관 결과 원문을 지우며 암호화 복사본도 파기 대상이다. 파일 권한이 달라진 결과의 이름 노출도 차단한다. 만료 정리·취소·삭제는 원문 없는 감사만 남긴다.
5. **화면**: 기존 응답 필터로 작업 생성, 현재 작업 목록/진행률·완료 다운로드·실패/만료 안내·취소/삭제를 연결한다. 새로고침 뒤 DB 상태를 복원한다. 도메인 상태를 localStorage에 저장하지 않는다. 현재 권한 DTO로 버튼을 표시하고 서버의 409/410/413 오류를 안내한다.
6. **계획/문서**: Prisma migration·모델 문서·DTO/OpenAPI/정책·worker 운영 안내·TASKS/P06-T02 증거를 실제 구현에 맞춰 갱신한다. 기존 즉시 다운로드와 비동기 결과의 차이와 보유 기한을 설명한다.

## 필수 검증

- 분리한 PostgreSQL 시험 DB에서 생성/목록/상세/취소/삭제, 같은 키/동시 claim, 재시작·lease 회수, 빈 결과·5,001건 이상·열/바이트 한도를 검증한다.
- 현재 회사·역할·서비스 grant·전문가 배정·세션, 실행 중 취소/권한 회수와 다운로드 후 감사, 다른 회사 ID/파일 이름·원문 비노출을 확인한다.
- 실제 CSV 바이트·한글/개행/따옴표/수식·행렬/복수 선택·새 게시 버전과 원천 DB를 대조한다. 생성/처리 후 정정·파기·기간 변경·만료 시 이전 결과의 다운로드 차단·암호화 원문 제거를 확인한다.
- 변경에 맞는 타입·린트·관련/전체 회귀·production 빌드, migration의 빈 설치/업그레이드와 계약/계획을 통과한다. 실제 API는 합성 회사의 해당 내보내기 작업만 처리하고 전역 production worker는 실행하지 않는다. 재시작 후 결과 해시·상태·현재 권한을 대조한다.
- Ego TaskSpace 34의 명시적인 제어 재개 응답 이후 실제 화면·390px·저장소 초기화·다운로드를 검증한다. 원본/선행 P06-T01과 운영 외부 저장소 검증 전에는 P06-T02를 완료로 집계하지 않는다.
