# 템플릿 CRUD·전체 복제 검증

2026-10-02. 회사 내 서비스 템플릿의 실제 DB 저장과 화면을 구현했다. 모든 원본 템플릿이나 폼 모듈 전체가 완료된 상태는 아니다.

## 구현 범위

- 템플릿 생성·목록·검색·분류·미리보기·전체 내용 편집·물리 삭제.
- 서비스별 접근 권한. DB 복합 FK로 다른 회사의 서비스 연결 금지.
- 질문·선택지·본문·서식·동의 목적·보유 기간·응답 한도 전체 복제.
- 새 폼과 질문 ID 생성, 버전 충돌 검사, 중복 생성 방지.
- 템플릿 변경·삭제 이후 기존 복제 폼과 응답 유지.
- 폼 목록의 ‘템플릿 등록’으로 기존 폼의 전체 내용을 템플릿 편집기에 불러올 수 있다.

## 실제 검증

Ego에서 템플릿 생성 → 저장된 내용 편집 → 미리보기 → 새 폼 생성 → 원본 템플릿 삭제를 실행했다.

- 처음 질문 두 개, 드롭다운 두 선택지, 보유 기간 45일, 응답 한도 7건으로 저장.
- 질문 이름과 선택지를 수정하고 보유 기간을 60일로 변경.
- 새 폼에서 수정한 질문·선택지·동의 목적·60일·7건이 유지됨을 확인.
- DB에서 원본과 복제본의 질문 ID가 다름을 확인.
- 원본 템플릿 삭제 후 새 폼 내용이 그대로 남는 것을 DB에서 확인.

## 아직 확인하지 못한 범위

원본 25개 공용 양식은 제목·설명·이미지만 관찰된 상태다. 질문 구성을 추정하여 채우지 않았다. 해당 카드는 미리보기 전용으로 표시하고, 제목만 복사하던 사용 동작을 제거했다. 이 25개 질문 구성과 원본의 분기·행렬·본인인증·첨부 기능은 추가 구현·검증 대상이다.
