# R03-T02 회사·서비스·초기 설정 서버 API 완료 검증

2026-10-11 현재 소스와 실제 `catchsecu_test` PostgreSQL에서 회사·서비스·사업자 파일·컨텍스트·서비스 접근 요청 API를 다시 검증했다.

## 결과

- OpenAPI의 관련 9개 경로, 20개 작업이 모두 `implemented`로 연결돼 있다.
- 회사 생성·목록·상세·수정·폐쇄 요청/취소, 사업자 파일 업로드·다운로드·교체·삭제를 확인했다.
- 서비스 생성·검색·수정·보관·복원·현재 컨텍스트 선택을 확인했다. 재로그인 뒤에도 수정 상태가 유지된다.
- 다른 회사의 company/service/request ID 주입은 404/403으로 차단되고 DB와 감사 이력은 바뀌지 않는다.
- 동일 서비스명 동시 생성은 201/409 한 건씩, 동일 버전 동시 수정은 200/409 한 건씩으로 수렴하며 감사도 한 건만 남는다.
- 활성 구독 없음은 402, 서비스 한도 경합은 하나만 생성, archived 서비스 복원도 현재 한도를 다시 검사한다.
- 사용 중 서비스는 보관을 409로 거부한다. 이미 보관된 서비스는 폼 쓰기·게시·공유 생성·공개 제출·메일 작업을 차단한다.
- 접근 요청의 생성·목록·승인·거절·취소, 중복 수렴, 권한 부여와 멤버 버전 증가를 한 트랜잭션에서 확인했다.
- DB 잠금 대기 중 세션 만료·MFA 의무화·멤버 정지/역할 변경을 재검사한다. 실패 시 업무 행·권한·감사 변경이 함께 롤백된다.
- 관련 12파일 257시험이 통과했다. 같은 소스에서 typecheck, 대상 ESLint, production build 82페이지도 통과했다.
