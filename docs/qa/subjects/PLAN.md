# 정보주체 조회·동의 철회 구현 계획

대상: P06-T05와 P06-T01/P07-T01의 명시적 정보주체 연결, P08/P09의 발송 차단 연결. 전체 목표는 기존 181경로·72 Task 그대로 유지한다.

## 원본·현재 코드 근거

- 원본 find는 이름·이메일·필수 동의·한국어/English, find/complete는 존재 여부를 밝히지 않는 발송 안내다.
- agree/action history의 실제 토큰 화면과 formComplete/form-interrupt 정상 상태는 미확정이다. 독립 구현의 상태·권한 계약을 명시한다.
- 현재 폼은 질문 제목과 일반 타입만 저장하며 응답자를 식별할 역할이 없다. 제목으로 이름·이메일을 추정해 과거 답변을 연결하지 않는다.

## 구현 순서

1. **명시적 식별 항목**: Question.subjectRole(name/email/null), 폼 편집 UI 선택. 둘 다 필수 단문 질문에 각각 1개만 지정해 게시할 수 있다. 이메일/이름 형식 검증. CSV에도 열 역할을 직접 선택하게 하고 행 검증·worker에 전달한다. 기존 게시본은 불변이며 소급 분류하지 않는다.
2. **DataSubject**: 회사·서비스·정규화 이름/이메일 HMAC으로 구분하고 연락처는 암호화한다. 제출·CSV 반영 때 Submission에 연결한다. 식별 답변 정정 때 재연결하며, 마지막 연결이 사라지면 개인정보 레코드와 인증 범위를 제거한다. 실제 파기도 같은 정리 함수를 호출한다.
3. **이메일 증명**: 이름+이메일 조회는 항상 같은 202 응답. 일치하는 유효 자료에만 암호화 메일 작업을 만든다. 요청 브라우저 연결·일회용 메일 토큰(10분)·요청 제한. 링크 GET은 소비하지 않으며 버튼의 POST로 인증을 확정한다.
4. **SubjectSession**: 요청 시 찾은 DataSubject 범위 고정, HttpOnly·SameSite=Strict·HTTPS Secure 쿠키, 30분 만료. 메일 URL 토큰을 세션의 비밀 없는 ID로 교체한다. URL의 ID와 쿠키 세션이 일치해야 하며 현재 회사·서비스·응답 보유 상태를 매번 확인한다.
5. **본인 이력**: /infoOwner/agree-history/:id와 action-history/:id에 해당 정보주체의 동의 영수증·동의/철회 이벤트만 표시한다. 답변 전체·담당자 메모·정정 원문은 노출하지 않는다. 페이지·기한·종료 안내와 로그아웃 포함.
6. **철회 흐름**: 요청(requested)→확인(completed) 또는 취소(cancelled). form-interrupt는 서버의 실제 요청을 조회해 확인/취소하며 formComplete는 서버에서 완료된 상태만 표시한다. 직접 URL로 완료 성공 화면을 만들지 않는다. 중복 확인은 동일 결과, 동시 정정·파기·철회는 행 잠금으로 검사한다.
7. **발송 차단**: 확인 시 Submission withdrawn, ConsentEvent, 서비스별 연락처 HMAC Suppression을 원자 저장한다. 관리자 철회도 같은 차단을 적용한다. 연락처/서비스 범위를 가진 메시지는 enqueue와 실제 worker 전달 직전에 suppression을 검사한다. 인증 등 필수 트랜잭션 메일은 별도 목적이다. 이후 P08/P09의 동의·캠페인 CRUD에서도 이 검사를 사용한다.
8. **검증**: 실제 DB/API에서 명시적 매핑/CSV/정정/파기, 회사·서비스 범위, 이름·이메일 존재 추측 방지, 브라우저 바인딩·토큰 소비/만료·다른 세션 URL, 목록·이벤트·철회/취소/중복/경합, 예약된 메시지 차단을 테스트한다. Ego에서 합성 폼→응답→조회 요청→실제 로컬 메일→동의/행동 이력→철회 취소·확정→관리자 상태→공유 차단 확인. 외부 SMTP와 전체 선행 게이트는 실제 증거 없이는 완료 처리하지 않는다.

## 삭제·보존

DataSubject는 마지막 연결 삭제 시 제거한다. 인증 요청·세션은 기한 종료 후 정리하며 로그에는 코드·이름·이메일 원문을 넣지 않는다. Suppression의 HMAC은 재발송 방지 자료로 개인정보 원문과 분리한다. 백업·외부 전달 사본과 운영상 보존 기간 최종 설정은 별도 후속 게이트다.
