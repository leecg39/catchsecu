# 구조화 처리방침 데이터 모델·서버 검증

2026-10-10. R10-T01~T04의 부분 수용 기록이며 전체107작업 완료가 아니다.

- `DocumentPolicyDraft`를 문서당 0..1개로 추가했다. 회사·서비스·문서 복합 FK, 처리방침 유형 guard, 스키마 버전·JSON 크기 제약을 적용한다. 문서의 기존 version/쓰기 잠금과 같은 트랜잭션에서 저장·제거·감사를 수행한다.
- 문서 생성·상세·수정 API의 `policyDetails`는 선택 항목이다. PATCH 생략은 기존 값을 보존하고 명시적 null은 제거한다. 동의서 유형에는 구조화 처리방침 입력을 거부한다.
- 아동/법정대리인, 인프라·개발 수탁자/재수탁자, 미사용·탈퇴 회원, CCTV, 자동화된 결정, 책임자/권리 부서/국내대리인/DPO, 민감정보/국외이전/기기내부/광고/보존 항목을 엄격한 DTO로 검증한다. 작성 중 값은 초안에 보관하고, 활성 구역의 필수 입력은 게시 전에 검증한다.
- 게시본에는 해당 시점의 구조화 자료를 복사한다. 선택하지 않은 구역의 숨은 초안 입력은 공개 JSON에서 제거한다. 미리보기·공개 본문·비교·PDF는 같은 텍스트 렌더러를 사용한다. 기존 구조화 자료가 없는 스냅샷에는 새 키를 넣지 않는다.

DB 시험에는 명시적 제거와 과거 클라이언트 PATCH, 누락 항목의 게시 거부, 권한/회사/서비스/유형 거부, 낡은 version409, 감사 기록 실패 시 개정·관계·JSON 원자 롤백, 게시 후 변경/제거/보관에도 과거 스냅샷과 PDF 바이트 유지가 포함된다.

원본 상태102개 항목의 대응은 [구현 대응표](../source-field-audit/implementation-map.csv)에 기록했다. 98개는 독립 DTO로 정규화했고2개 수탁 유형은 부모 구역에서 구분한다. 클라이언트 초기화 배열2개의 동적 동등성은 추가 검토 대상이다. 원본 API wire 형식이나 접근 불가능한 원본 유료 화면의 완전한 동등성을 주장하지 않는다. 문자열/배열/128KiB 제한 중 관찰하지 않은 값은 구현 자원 제한이며 법적 보유기간 기준이 아니다.

복구 리허설의 첫 실행은 디스크 부족으로 중단됐다. `db-rehearsal-104-enospc`에 별도 남겼으며 해당 결과를 통과로 집계하지 않는다. 재생성 가능한 이번 작업의 빌드 캐시·중간 추출물만 정리한 뒤 재실행했다. 소스·서명 검증 자료·설치된 ClamAV·앱 데이터는 유지했다.
