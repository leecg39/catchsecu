# 게시 문서의 제공·수탁자 출처 보존

2026-10-10. [실제 응답 재현](before.json): 수집 목적을 통해 수탁자가 포함된 게시 문서가 공개 제공·수탁 목록에서 누락된다. 서버가 게시 스냅샷 대신 현재 `DocumentRecipient`만 참조한다. 초안의 직접 연결을 바꾸면 이전 게시본의 수탁자 ID 필터도 바뀐다.

## 보완 설계

- 게시 당시 직접 연결과 목적 연결의 제공·수탁자를 합쳐 중복 제거한 `DocumentVersionRecipient` 관계를 동일한 게시 트랜잭션에서 기록한다.
- 회사·서비스·문서·게시 버전의 복합 FK 및 제공·수탁자의 복합 FK로 범위를 고정한다. 공개 후 관계 추가, 수정, 삭제를 DB에서도 거부한다.
- 공개 목록의 제공·수탁자 유무와 국가는 게시된 본문 스냅샷을 따른다. 특정 수탁자 ID 필터는 게시 버전에 고정된 관계만 따른다.
- 기존 `DocumentVersion.snapshot`, 렌더링, 해시, PDF, 동의 영수증은 수정하지 않는다. 따라서 출처 ID를 기록하지 않았던 과거 버전은 이름으로 ID를 추정하거나 현재 연결로 소급하지 않는다. 일반 공개 목록에는 스냅샷 기준으로 포함하고 특정 ID 필터에는 포함하지 않는다. 새 게시 시부터 출처를 기록한다.
- 내부 출처 ID를 공개 문서 DTO에 추가하지 않는다. 기존 공개 본문 계약과 해시를 유지한다.

이 변경을 위한 실패 회귀를 먼저 작성했고, 최종 전체시험은 이 보완 이후 다시 실행한다. R10 전체 모델의 아동/CCTV/자동화 결정 등 필드 대조는 별도 잔여 작업이다.
