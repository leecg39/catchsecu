# 공유 열람자 CRUD·인증 점검

2026-10-04. P06-T04는 진행 중이다. P06-T02/P09-T02의 전체 선행 게이트와 정상 원본·Ego·외부 메일/운영 보존 조건을 통과해야 완료로 판정한다.

1. 기존 공유 모델·복합 FK·암호화 이메일·인증 코드/세션·관리/열람 화면을 확인한다. 생성 재전송의 파일 권한/보관 상태·회수/만료와 관리 작업의 실제 세션 만료를 PostgreSQL로 재현한다.
2. 생성 재전송을 현재 권한과 공유 자원에 연결하고 이메일/항목/기한 변경·재발송·회수 시 신규/이전 캐시 원문을 제거한다. 기존 DB 모델과 불변 공유 이력을 유지한다.
3. 서버가 현재 서비스/폼 상태와 파일 권한으로 초대·수정·재발송·회수/항목 선택 가능 여부를 반환한다. UI는 이 결과와 서버가 보정한 페이지를 사용한다. 알려지지 않은/중복 검색 키를 거부한다.
4. 잠금 대기·성공 감사 저장 중 실제 세션/인증 기한 만료를 검사한다. 종료 요청은 신규 공유·메일·인증 세션과 성공 감사를 롤백한다. 인증 실패 횟수와 일회 소비는 유지한다.
5. 관련/전체 회귀·타입/린트·production 빌드 후 독립 합성 계정으로 실제 CRUD·이메일 인증·범위 변경·재발송·회수·다른 필드/파일 차단을 HTTP로 확인한다. 서버 재시작 후 업무/기존 원본 해시와 독립 SQL 결과를 대조한다.

Ego TaskSpace 34 재개 승인은 대기 중이며 브라우저를 호출하거나 다른 창으로 우회하지 않는다. HTTP HTML 응답을 UI 조작 검증으로 집계하지 않는다. 사용자 관리자 계정/기존 업무 자료를 바꾸지 않고 전역 발송/파기 worker를 실행하지 않는다. 메일은 독립 합성 수신자의 암호화 로컬 작업만 사용하며 외부 SMTP 성공을 대신하지 않는다.
