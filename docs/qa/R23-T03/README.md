# R23-T03 대시보드·통계·월마감 화면 검증

대시보드 전체/서비스 화면, 개인정보·마케팅 통계, 준수·월마감 출력 화면을 실제 API와 URL 상태에 연결했다.

- 대시보드와 두 통계 화면의 기간·검색 조건, 월마감의 월·범위·출력 페이지·페이지 크기를 URL에 보존한다.
- 개인정보 화면은 보유·기간 접수·보존 조치·동의 철회·정보주체 철회·파기를 전용 집계로 표시한다.
- 마케팅 화면은 현재 상태와 기간 이벤트를 전용 분석 API로 표시한다.
- 월마감 출력은 10/20/50/100 행 크기, 이전/다음 페이지와 범위 초과 페이지 보정을 URL과 동기화한다.
- Ego Lite에서 재시작 전 기능 8개·반응형 8개, 재시작 후 저장 세션·새 로그인 포함 기능 11개·반응형 8개를 검증했다. 1440px와 390px에서 가로 넘침과 런타임 오류는 0건이다.
- TypeScript와 변경 파일 ESLint 오류 0건(기존 `<img>` 경고 4건), production build 83페이지가 통과했다. 최초 빌드는 로컬 공급자 허용 플래그 누락으로 보호 장치가 중단했으며 올바른 로컬 QA 플래그로 재실행했다.
