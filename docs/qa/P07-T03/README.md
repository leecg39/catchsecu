# P07-T03 보존·파기 처리 보완

2026-10-04. 전체 작업 상태는 **진행 중**, 공식 완료는 **15/72**다. 현재 범위의 구현과 실제 검증을 기록한다.

## 구현한 동작

- 파기 목록은 현재 회사·계정·세션·MFA·비밀번호 정책·서비스 권한을 검사한다. 접근 가능한 서비스가 없어도 로그인 검사를 생략하지 않는다. 전문가 계정은 기존 viewer 역할을 유지하며 임의 grant로 파기 권한을 얻지 못한다.
- 승인·반려·예약 취소·일정 변경·재처리·보존 조치·보유 기한 변경·증명서 조회는 잠금과 감사 저장 이후에도 실제 기한을 검사한다. 늦은 요청은 원문 변경·이력·감사를 함께 롤백한다.
- 검색·정렬·페이지 보정을 적용하고 중복/미지원 쿼리를 거절한다. 항목별 작업 권한과 보정된 페이지를 화면에 연결한다. 증명서 상세는 현재 권한으로 다시 조회하며 무결성 실패는 성공 열람 감사와 다운로드를 남기지 않는다.
- worker는 lease 소유자·시도 번호·실제 기한으로 실행을 구분한다. 같은 작업자 이름으로 재획득한 뒤에도 이전 실행이 완료·재시도 상태를 덮어쓰지 못한다. 실패한 시도는 원문 없는 감사 기록을 남긴다.
- 연결된 본인인증·전자서명 영수증을 삭제하면 DB 트리거가 이벤트와 암호화 인증 요청까지 삭제한다. 증명서에는 종류별 건수만 남긴다. 파기 시작 뒤 영수증 재연결과 인증 원문이 남은 증명서 생성을 DB에서 거절한다.
- 기존 export 원문 무효화 트리거를 유지한다. 파기 시작의 Submission 변경은 연결된 내보내기 조각·조건·응답 원문을 같은 DB 트랜잭션에서 제거한다.

## 검증

| 항목 | 현재 결과 |
|---|---|
| 관련 PostgreSQL 테스트 | 2파일 75개 통과, 실패/대기 0 |
| 전체 회귀 | 54파일 772개 통과(605.18초), 실패/대기 0 |
| 실제 HTTP | 새 빌드 33개 + 재시작 7개 = 40개 통과 |
| 실제 파일 | 합성 바이트 업로드·ClamAV·접수·암호화 객체 삭제·재시작 후 다운로드 410 |
| DB 원문 | 답변·메모·정정·동의 영수증·정정 payload 0, 요청 사유 2개 제거, 캐시 3개 원문 제거 |
| 남은 합성 세션 | 0 |
| 기존 업무 보존 | 회사 27개·계정 29개와 연결 업무의 해시 유지 |
| 마이그레이션 | 개발·시험 DB 62개 체크섬 일치, 기존 61개 SQL 유지, 새 보호 trigger 4개 |
| 타입·린트·빌드 | 통과. 전체 lint 오류 0·기존 경고 21 |
| 현재 브라우저 UI | 미검증, Ego 기존 TaskSpace 34 재개 승인 대기 |

실제 개발 DB에서는 tenantId/requestId를 지정한 합성 요청 하나만 worker로 실행했다. 전체 메일·파기 처리기는 실행하지 않았다. 두 종류의 인증 영수증·4개 이벤트·2개 암호화 요청의 삭제는 **시험 DB의 합성 제약 fixture**로 검증했으며 외부 본인인증·전자서명 성공으로 집계하지 않는다.

초기 관련 검증의 증명서 정렬 오류를 수정했다. 기존 테스트의 회사 전체 정정 payload 0 가정은 해당 응답의 payload 0 검사로 바꾸어 다른 응답을 보존한다. 전문가 fixture는 실제 DB의 viewer 제한을 유지하도록 고쳤다. 첫 빌드의 로컬 메일 플래그 누락도 수정했다. 실패한 초기 실행은 최종 통과 결과에서 제외하고 별도 JSON으로 보존한다.
