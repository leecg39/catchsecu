# 헬프센터 가이드 DB·PDF·운영 화면: P13-T01 부분 검증

2026-10-03. 원본 헬프센터의 10개 묶음·PDF 35건을 전역 `Guide` 자료로 초기화하고 `/help-center`를 서버 목록·검색 화면에 연결했다. 시스템 운영자 화면 `/admin/guides`는 초안 작성, PDF 등록·교체, 분류·문서 순서 변경, 게시·게시 취소, 미리보기·보관을 제공한다. 기존 `/assets/help/*.pdf` 정적 공개 경로는 제거하고 회원·운영자 권한을 검사하는 다운로드 API를 사용한다.

## 구현과 권한

- Migration 45: `Guide`의 분류/순서, 제목, 게시 상태, 파일 이름·크기·SHA-256, 초기 자산 키 또는 암호화 저장 키, 버전·시각과 DB 제약·인덱스.
- [원본 PDF 목록·해시](source-manifest.json): 35건, 합계 22,137,145바이트. `scripts/seed.ts`는 원본 PDF 형식과 해시를 확인하고 기존 운영자 수정분을 덮어쓰지 않는다.
- `GET /api/v1/guides`와 `/:id`, `/:id/download`: 로그인과 활성 회사 소속을 확인한다. 시스템 운영자는 회사 없이도 `scope=admin`·`preview=1`을 사용한다. 일반 계정의 초안·보관 자료는 404다.
- 시스템 운영자만 `POST`, `PATCH`, `PUT /:id/file`, `DELETE`를 사용할 수 있다. 생성은 멱등키, 수정·파일 교체·보관은 버전을 검사한다. 초안에 PDF가 없으면 게시할 수 없다.
- PDF 교체는 10MB 제한, 확장자·내용·해시 검사와 ClamAV 검사를 거쳐 암호화 비공개 저장소에 쓴다. 공개 다운로드는 저장된 크기·해시를 재검사하고 attachment, no-store, nosniff, sandbox 헤더를 보낸다. 교체·보관 시 이전 암호화 파일을 제거한다. 변경과 다운로드를 감사한다.

## 남은 수용 조건

P13-T01의 문의·개선 제안 저장·답변, 공지 첨부 일관성, 원본에서 확인되지 않은 운영 화면 세부 동작과 모든 역할·새 브라우저 E2E가 남아 있다. 파일 삭제가 디스크 오류로 실패했을 때 재시도할 영속 작업 큐도 후속 구현이 필요하다. 배포 시 `assets/help-pdfs` 35개 비공개 원본 파일과 암호화 저장소를 함께 제공해야 한다. 외부 운영 사이트의 자료는 변경하지 않았다.
