# Mock 대체 및 내부 잔여 실행 계획

2026-10-06 사용자 지시: 외부 증명을 Mock Data로 대체하고 구현 가능한 작업을 먼저 모두 수행한다. 실제 공급자 수용은 별도 보관하며 mock 검증 완료와 혼동하지 않는다.

1. 결제 승인/실패·환불 중복/경합 및 가상 PG와 웹훅 간 직렬화: 실패 재현 → 구현 → PostgreSQL 회귀.
2. 기존 OIDC/SAML·가상 조직·PG·SMTP·SMS·카카오·알림·S3 모의 검증을 재실행 가능한 단일 실행 명령과 결과 보고서로 묶고, 누락된 모의 경계 검증을 추가한다.
3. 전체 서버 회귀·타입·린트·빌드·계약 검사를 실행하고 실제 실패를 수정한다. 각 검증에서 실패·skip·외부 미검증을 표시한다.
4. Mock 대체 범위와 내부 검증 증거를 작업별로 연결한다. 원본 화면/실운영 PITR 등 mock으로 실제 사실을 입증할 수 없는 부분은 모의 대체임을 명시한다.
5. 적대적 검토·수정 후 커밋·푸시 및 다음 잔여 목록 갱신.
