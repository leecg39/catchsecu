# 의존조건과 미확인 사항

계획 작성 자체를 막는 의존조건은 없다. 아래는 구현·최종수용의 조건이다.

| ID | 항목 | 영향·처리 |
|---|---|---|
| B01 | 원본 유료/Enterprise 정상화면 미관찰 | 해당화면 동일성 주장 불가. 캡처확보 또는 독립설계 라벨. 내부 CRUD 진행가능 |
| B02 | SMS/카카오/메일/PG 실제시험계정·수신자·도메인 | 로컬구현 진행, 제공사시험은 external_pending |
| B03 | GPKI/새올/그룹웨어·본인인증 규격/환경 | mock과 실제 분리, 어댑터계약 확정 필요 |
| B04 | 기존 migration checksum 차이 기록 | 현재DB이력 재검증·백업, 기존 SQL 임의수정금지 |
| B05 | 기존 수정중 결제 코드·계약·진행판 | 작업트리보존·증거로통합, 덮어쓰기금지 |
| B06 | 보존/요금/환불/권한의 원본 미확인 정책값 | 버전있는설정·제품규칙 확정; 추정값으로 법률/원본동일성 주장금지 |
| B07 | staging 저장소·키·백업/복구 환경 | 격리local 검증을 먼저 수행, 최종복구/배포게이트는 별도 |

상세는 [외부 연동](../../external-integrations.md), [차이 분석](../../scope-gaps.md)을 따른다. 해결되지 않은 최종 검증은 완료 체크를 하지 않는다.
