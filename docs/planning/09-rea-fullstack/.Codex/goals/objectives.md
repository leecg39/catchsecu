# 목표와 마일스톤

계획 목표: 원본186경로를 빠짐없이 모델·API·UI·검증·의존성으로 분해한다. 계획 산출물 생성 및 검산이 현재 목표다.

구현 목표: 각 페이지의 정상 동작을 영속DB·서버권한·실제브라우저·재시작으로 검증하고 외부 의존성이 있는 기능은 실제 시험환경까지 확인한다. 원본과 미확인 정상화면의 동일성을 추정하지 않는다.

| 마일스톤 | Phase | 완료 기준 |
|---|---|---|
| M1 기준선·공통·조직·인증·보안·과금 기반 | R00~R07, R21 | 스키마·세션·tenant·권한·정책·원장 로컬 게이트; 외부인증/PG는 별도 최종검증 추적 |
| M2 문서·폼·승인게시 | R08~R10 | 버전불변·단계저장·문서/PDF·승인·게시·중단·고정URL |
| M3 개인정보 수명주기 | R11~R16 | 실제제출·첨부·공유·정보주체·import·동의·보존파기 |
| M4 발송·연동 | R17~R20 | SMS/메일/카카오/알림 CRUD·queue·receipt·억제·중복과금방지 |
| M5 감사·집계·콘텐츠 | R22~R24 | 실제업무로그·통계·월마감·공지/도움말·모든 fallback |
| M6 최종 수용 | R25 | 전경로·교차흐름·외부서비스·복구·UI 수용, 필수미완료0 |

M번호는 결과물 묶음이며 실행순서는 tasks.json DAG를 따른다. 로컬게이트와 전체완료 게이트는 acceptance.md에서 구분한다.
