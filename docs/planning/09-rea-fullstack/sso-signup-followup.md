# R07 후속: OAuth 가입 확인·동의

원본 `$fr`(@15225960)은 서버가 준 인증 결과를 표시하고 만14세·서비스 약관 동의를 받아 가입한다. 회사명은 초대 회사 표시이며 새 회사 생성 입력이 아니다. 점검 당시 로컬 `/oauth2/signup`의 이메일/비밀번호 폼이 원본과 달라 아래 기능을 보완했다. 아래 항목이 끝나기 전 R07-T01~T04 전체를 완료로 올리지 않는다. 기존107개 작업의 하위 작업이며 외부 원본 토큰 규격을 추측하지 않는다.

## R07-T01 모델·계약

- [x] OIDC가 검증한 신규 신원에만 발급하는 일회성 가입 요청을 저장한다. 원문 subject/state는 암호화하고 공개 토큰은 해시 저장한다. 회사/공급자 FK·공급자version·원래 state 만료·브라우저hash·초대 결합을 유지한다.
- [x] 원래 인증 state는 callback에서1회 소비한다. 가입 요청 기한은 원래 인증 기한과5분 중 빠른 시점으로 제한한다. 계정/구성원/로그인 세션은 동의 전 생성하지 않는다.
- [x] 필수 연령 확인·약관 버전·동의 시각을 사용자에 연결해 기록한다. 이메일·이름·회사명을 클라이언트 가입 입력으로 받지 않는다. 데이터 보존/탈퇴와 관계 삭제 정책도 명시한다.
- [x] 기존 사용자 로그인·명시적 계정연결은 가입 요청을 만들지 않는다. SAML/가상기관의 기존 흐름 변경 여부를 별도 계약으로 구분한다. 현재 누락의 직접 범위는 OIDC 신규 가입이다.

## R07-T02 서버

- [x] `completeSso`의 검증·트랜잭션을 재사용할 수 있게 나누고 신규 OIDC 신원은 가입 요청 발급으로 전환한다. 공급자 정책·IP·상태/version·이메일 검증·초대 최신version을 발급과 수락 양쪽에서 검사한다.
- [x] 안전한 HttpOnly 가입 쿠키와 원래 브라우저 결합으로 조회한다. 요청에 실린 원본 `data`/`enc`·이메일·이름만으로 신원을 승인하지 않는다. GET은 비밀subject/token을 제외한 표시 DTO만 반환한다.
- [x] 동의 수락은 Origin·rate limit·가입 쿠키·브라우저·기한·현재 권한/공급자/초대를 검증하고 사용자/연결계정/구성원/동의/세션/감사와 요청 소비를 단일 트랜잭션으로 커밋한다.
- [x] 중복·동시 수락은 한 번만 성공한다. 계정 충돌·감사 실패·마지막 기한 만료는 전부 롤백한다. 요청 취소·만료·공급자 삭제 후 잔여 개인정보 정리를 연결한다.
- [x] OpenAPI/operation-policy/handler 추적과466개 기준 이후 증가분을 함께 갱신한다. 기존 회귀에 새 동의 단계를 반영하고 과거 HTTPS 동결 fixture는 보존한다.

## R07-T03 화면

- [x] `/oauth2/signup`에서 서버의 인증된 이메일·이름·초대 회사명을 읽기 전용으로 표시한다. 만14세와약관 필수 체크, 전체 동의, 현재 문서 링크, 저장 중 중복 방지, 만료/재사용/충돌/실패 복구를 연결한다.
- [x] 무효 직접 진입은 SSO 재시작을 안내한다. 일반 `/signup`은 기존 이메일 가입을 유지한다.
- [x] 새로고침은 남은 가입 요청을 복원한다. 암호나 원본 외부 토큰을 브라우저 저장소에 저장하지 않는다.

## R07-T04 검증

- [x] 실제 시험 IdP 인증 후 동의 전 사용자/세션0, 정상 수락 후 정확히1, 초대 role/grant/감사/동의 일치 확인.
- [x] 회사/브라우저 교차, 위조 표시값, 누락 동의, 공급자version 변경, 초대 폐기·만료, 재전송·경합, 감사 실패 롤백 시험.
- [x] Ego에서 표시·체크·에러·새로고침·재로그인·390/768/1440폭 확인. 새 서버에서 같은 DB/기한/소비 결과를 재조회한다.
- [x] 실제 Google/Microsoft 계정 수신은 기존 외부 대기로 분리한다. 로컬 시험 IdP 성공을 공식 제공사 성공으로 집계하지 않는다.
