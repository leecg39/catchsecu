# 외부 연동·확인 의존성

로컬 DB·CRUD·UI와 최종 외부연동을 분리한다. 서비스사 계약과 시험계정이 없는 항목은 해당 외부검증만 대기하고 내부 구현은 진행한다. 실제 원본 캐치시큐 계정을 발송/결제/삭제 시험에 사용하지 않는다.

## 제품 규칙 확인

정확한 요금·환불 산식·보존기간·법적 최소기간·자동화결정/CCTV 등의 의무를 UI나 번들에서 추론하지 않는다. 현재 코드의 구성값과 역공학 필드를 먼저 대조하고, 실제 정책 담당자의 입력이 필요한 항목은 버전 있는 설정으로 관리한다. 본 계획은 법률 적합성을 판정하는 문서가 아니다.

자격증명은 저장소/계획문서에 평문으로 쓰지 않고 환경 또는 비밀관리 경로로 주입한다. 실제 외부 발송·결제 QA가 필요해질 때 시험 대상·허용 범위가 확정되지 않았다면 그 항목만 사용자에게 확인한다. 지금 계획을 작성하거나 로컬 CRUD를 구현하는 데 추가 승인을 요구하지 않는다.
