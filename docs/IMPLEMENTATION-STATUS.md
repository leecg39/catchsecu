## 검증과 남은 범위

최근 전체 PostgreSQL 회귀 시험은 26개 파일·414개 통과했다. 서비스 접근 요청의 실제 HTTP 생성·중복·승인·권한 반영, 전문가 배정·회사 선택·회수 후 재선택 차단, 접근 오류의 사유별 리디렉션, 감사 조회·CSV의 회사/권한 격리·원장 수정 차단과 GET 로그아웃의 세션 유지를 확인했다. 집계 API의 회사/서비스 범위·기간·보유 상태·한국 시간 월 경계와 수신거부 재집계 시험, 7개 집계 화면의 production HTTP 200과 독립 DB 건수 일치, headless Chromium의 실제 수치·기간 필터·390px 화면도 확인했다. 결제 내역은 무료 체험 이력의 회사 범위·권한·월 필터·미승인 요청 제외를 시험하고, production HTTP/독립 DB 대조와 390px 화면을 확인했다. 크레딧 원장은 동시 예약·중복 원천·정산 범위·불변성과 API 권한, 독립 DB/브라우저 대조를 확인했다. TypeScript·변경 파일 ESLint(오류 0)·production build를 통과했다. 이 수치는 181개 경로의 전체 수용 조건 통과를 뜻하지 않는다.

## 로컬 실행

```sh
# .nvmrc의 Node 버전을 사용한다.
npm ci
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

- 앱: http://localhost:3100
- 최초 DB·환경 설정: scripts/setup-local.py. 기존 설정을 덮어쓰지 않는다.
- 개발 계정 초기 암호: .local/catchsecu_dev-accounts.json. 이 파일은 Git에서 제외되며 권한 600이다.
- 메일·CSV 반영·파기·만료 자료 처리: npm run worker. 현재 로컬 메일 모드는 .local/catchsecu_dev/mail에 시험 메일을 기록한다. 파기 증명서는 현재 DB와 비공개 파일 저장소의 삭제 범위만 확인한다.
- 테스트: npm test. 별도 .env.test.local의 로컬 catchsecu_test만 허용한다.
- 외부 SMTP·문자·알림톡·결제 공급자는 실제 자격증명과 시험 환경을 연결한 뒤 검증해야 한다.
