# 의존조건과 미확정 사항

계획 작성에 대한 블로커는 없다. 아래 항목은 해당 구현/외부 검증 단계의 의존조건이다. 대기 항목이 있어도 독립 DB·API·화면은 진행 가능하다.

| ID | 필요한 항목 | 영향 Task | 해소 증거 |
|---|---|---|---|
| B01 | 원본 유료/동적 정상화면·작업 의미 | P00-T01/T03, 각 미검증경로 | 실제 화면/문서 또는 독립 구현 결정 기록 |
| B02 | 문자·카카오 공급자/테스트계정·발신자승인 | P08-T03, P09-T03/T04 | test credential·공급자 실제 receipt |
| B03 | 이메일 발신 도메인/DNS/공급자 | P09-T02 | 검증된 도메인·테스트함 수신·반송webhook |
| B04 | PG 가맹점 sandbox·callback/domain·요금환불정책 | P10-T02/T04 | 승인·환불·대사 결과 |
| B05 | OAuth/SAML IdP·GPKI/새올/그룹웨어 계약·SDK·테스트환경 | P11-T03/T04 | 성공·오류·회수 SSO 실제 흐름 |
| B06 | 본인인증/전자서명 제공사와 sandbox | P06-T06 | 검증 영수증·문서해시·서명callback |
| B07 | Slack/Teams 테스트용 수신채널 | P09-T05 | 허용된 테스트채널에서 수신 확인 |
| B08 | DB·파일 저장소·비밀키·배포환경·백업 대상 | P01, P14-T03/T04 | 환경기동·migration·복원 리허설 |
| B09 | 보존·파기·환불·할당량 등 운영 정책 | P00-T03,P07-T03,P10 | 버전 있는 정책 결정·경계값 테스트 |

서비스사·가격·기간을 추론해서 상수로 고정하지 않는다. 공급자 미설정/외부시험 누락은 blocked이며 완료율 분모에서 제거하지 않는다. 비밀키는 코드·TASKS·채팅 로그 대신 환경 비밀 저장소에 둔다.
